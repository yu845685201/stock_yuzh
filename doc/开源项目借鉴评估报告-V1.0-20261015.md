# 开源股票分析项目 × stock_yuzh 对比评估报告

> **版本**：V1.0 · **日期**：2026-10-15
> **评估对象**：`refrences/doc/` 下 129 份开源项目深度分析文档（《开源股票分析项目深度分析索引-20261014.md》全部条目，10 大类，约 2.3 万行）
> **被评估系统**：`stock_yuzh`（A 股盘后静态分析系统：数据同步 + 分析链截面 + 六维复盘报告，CSV 交大模型解读）
> **评估方法**：① 按类别并行精读全部 129 份文档，提取能力池（数据源 / 指标策略 / 工程化机制 / 工作流设计）；② 对 stock_yuzh 做实测盘点（uat 库 188 张表行数与时间范围、CLI 39 个命令、18 分析模块、review 层源码）；③ 逐项标定差距。**凡文档未实证处标「推断」，本报告结论分【事实】【推断】【观点】三档。**

## 一、结论摘要（先看这里）

129 个开源项目中，**有明确借鉴价值的内容集中在五个方向**；同时 stock_yuzh 的数据资产厚度与质量工程在对比中处于明显上位，多数项目反而"羡慕而不可得"。

| 判断 | 内容 |
|---|---|
| **最值得抄的 5 件事** | ① 经典技术指标 + K 线形态库（我们完全空白）；② LLM 解读防幻觉三件套（数字接地门 / 证据编号 / 事实-推断-假设标注）；③ 估值口径 calc 函数库（我们存了 34.6 万财报行 + 694 万估值行却只做了简单 PE）；④ skill 回归测试体系（提示词 CI + 虚构 fixture）；⑤ 回测/因子验证最小闭环（IC 评估 + 前缀不变性测试） |
| **数据层可补的缺口** | 可转债、期货日行情、宏观（利率/LPR/社融/PMI）、逐笔/tick、ETF 期权、北向个股明细、港股池扩充（现仅 33 只）——均有现成接入方案可抄（akshare / adata / efinance / a-stock-data） |
| **我们已有的（勿重复建设）** | 涨停/连板/炸板/跌停/溢价/放量/新高新低截面、情绪四态周期 + 校准工具、赚钱效应反馈矩阵 + 连板溢价、候选池核验 + 30 日滚动战绩、六维报告 + digest HTML——初判"缺失"的晋级率/连板溢价/情绪周期/胜率核验经代码核实**均已实现**（见 §2.3 校正表） |
| **不建议借鉴** | 实盘交易通道、RL/ML 预测模型、重多智能体平台架构、实时盯盘——与"盘后静态分析 + 确定性计算 + 大模型解读"定位冲突 |

### 2.2 分析层与报告层

- **分析链 18 个截面模块**：limit_up_today / consecutive_limit_up / limit_down_today / burst_limit / limit_up_premium / big_mover / volume_surge / new_high_low / chg_5d / chg_20d / position_60d / ah_5d_diff / ah_premium / volume_trend / money_trend / r1_ladder_relay / r2_mainline_follow / r3_trend_new_high / r4_institution_seat；5 条链（daily_review / limit_up_scan / tomorrow_candidates / hk_stock_review / overseas_index_scan）。**全部为简单量价口径，无 MA/MACD/KDJ/RSI/BOLL/ATR 等经典指标，无 K 线形态识别，无缠论**（grep 实证）。
- **数据预检**：前复权断裂检测（|change_rate| 超制度上限）、缺行分流（孤立单日计存疑 / 连续≥2 日判疑似停牌）、存疑标记进 CSV 与 meta。
- **六维复盘报告**（review/）：市场环境（指数/成交额/涨跌家数/两融/量价四象限/外围）、板块主线（行业榜 + 申万二级 + 概念涨停聚集）、个股异动、情绪、基本面、昨日复盘 + 明日计划；**另有**：
  - `money_effect.py`：赚钱效应反馈矩阵（昨日涨停按板位 × 今日五分类）、昨日炸板修复、连板溢价、大面统计、涨跌幅分档；
  - `sentiment_calibration.py`：情绪四态（高潮→冰点→退潮→回暖/震荡）规则校准 + 网格搜索阈值提案；
  - `verifier.py`：候选池核验（R1-R4 胜率/超额 vs 全市场中位）+ 近 30 核验日滚动战绩，落库 `review_prediction_daily` / `review_verification_daily`（**表已建、历史待积累**）；
  - `digest.py`：图文并茂解读 HTML（内联 SVG，红涨绿跌）。
- **工作流**：`sync-review-all` 一键采集（~11-13 分钟）→ 三链截面 → `review generate` → stock-analysis-chain skill 编排大模型解读 → digest HTML；同一锚定日 CSV 逐字节一致（SHA-256 验证）；黄金样本回归 10 只代表股。

## 五、分级借鉴清单

### P0 — 强烈建议（直击痛点或低成本高收益）

#### P0-1 经典技术指标库（补最大空白）
- **来源**：`xgboosted/pandas-ta-classic`（224 指标 + 62 形态，纯 Python 免编译）、`mpquant/MyTT`（通达信口径：MACD 柱×2、KDJ span=5 EMA、ATR 简单平均）、`bukosabino/ta`（43 指标 + Wilder 递推口径）、`TA-Lib/ta-lib`（lookback/unstable period 分离的元数据设计）
- **落地路径**：新建 `src/analysis/indicators/` 纯函数库（口径来源显式标注：通达信版 / TA-Lib 版），先做 MA/MACD/KDJ/RSI/BOLL/ATR/OBV 七个最常用；每个指标声明 warmup 长度并过滤不稳定区；以"截面模块"形式接入链（输出最新值 + 多空排列状态，如 `MACD状态=金叉且柱放大`），**不落全历史宽表**（5820 只 × 36 年全算太重，【推断】按近 3-5 年滚动或只算入池个股）
- **预期收益**：大模型解读从"只会看涨停/放量"扩展到"会看趋势与超买超卖"，报告信息密度质变
- **成本**：中（一周内可出 7 指标 + 单测 + 对拍用例）

#### P0-2 K 线形态识别（扩展成本最低）
- **来源**：`TA-Lib/ta-lib`（61 CDL，±100/+200 强度分级）、`SpiralDevelopment/candlestick-patterns`（`required_count + logic(idx)` 最小抽象；**显式 `.001+` 防一字板除零**——A 股涨跌停场景 doji/star 会出 inf/NaN）
- **落地路径**：自建 21 形态布尔库（趋势上下文显式引入，如 HangingMan 需前两日最高价低于今日开盘）；输出 `形态=<名称>(强度)` 截面列
- **预期收益**：「个股异动」维度直接增强；与放量/新高模块天然组合
- **成本**：低

#### P0-3 LLM 解读防幻觉三件套（直击最大痛点）
- **来源**（三项目独立收敛到同一机制，可信度最高）：
  - `HKUDS/Vibe-Trading` **数字接地门**：模型用 figures 块声明每个数字角色（observed/derived/proposed/cited），程序按形状+证据核对，核不过的单个数字剔除而非整篇拒绝；
  - `vibe-astock` **三明治核对**：资料包证据 `代码 字段=值 单位(日期)[ev-哈希]` + bound/derived/loose 三档 + 编造编号单列示众 + 大表 cap 前 N 后 M 其余写缺口；
  - `AlphaBot` **三段标注**：【事实】/【推断】/【假设·待验证】+ 消息归因交叉验证矩阵
- **落地路径**：在 stock-analysis-chain skill 的解读指令中增加：① 每个数字必须挂 CSV 中的列名或报告章节；② 推断必须标注；③ 引用不存在的编号/数字 = 解读作废重写。配合 `verifier.py` 已有的三态规范（成立/不成立/数据不足）形成完整纪律
- **预期收益**：报告可信度从"模型自律"升级为"程序可验"，这是 CSV→LLM 链路的核心风险点
- **成本**：低-中（skill 提示词工程 + 少量校验脚本）

#### P0-4 估值口径 calc 函数库（点燃库存数据）
- **来源**：`simonlin1212/Vibe-Research` §3.3：扣非×4 年化 PE（防一次性项放大四倍）、`forward_cagr=(EPS[T+2]/EPS[T])^0.5−1`、四锚消化年数 `ln(PE/锚)/ln(1+CAGR)`（锚 18/22/25/30x）、前瞻 CAGR vs TTM 同比 10pp 交叉判读、PEG 低≠安全
- **落地路径**：我们已存 34.6 万财报行 + 694 万估值行，缺的是口径。在 review 基本面维度或新截面模块中实现上述函数，纯 Python 确定性计算，`calculation_id=sha256(函数+版本+参数)` 保证可复现
- **预期收益**：基本面维度从"罗列财务数据"升级为"估值消化能力判读"
- **成本**：中

#### P0-5 skill 回归测试体系（防提示词退化）
- **来源**：`yennanliu/InvestSkill`：契约 lint + 12 份真实模型 golden 输出回归 + 12 个变异输出必须失败 + **虚构公司 ZEPH 数据包**（数字永不腐烂、模型无法背答案）+ prompt diff token 预算 25% 纪律；`tradermonty/claude-trading-skills` 的 `--check` drift gate
- **落地路径**：为 stock-analysis-chain skill 建：① 解读输出契约 lint（必备章节/免责声明/存疑点名）；② 用历史锚定日（如 20260923）CSV 做 golden 回归；③ 变异测试（篡改数字的 CSV 必须解读失败）
- **预期收益**：skill 是交付链路最后一环，目前无任何回归保护
- **成本**：中

### P1 — 建议（中等成本，明确增益）

#### P1-6 回测/因子验证最小闭环
- **来源**：`microsoft/qlib`（IC/ICIR/RankIC/RankICIR 信号分析 + Alpha158 表达式因子）、`qusong0627/QuantMind`（规则化因子工厂：字段×算子×窗口笛卡尔 + 逐日 IC + |corr|>0.85 去重）、`shashankvemuri/Finance`（信号/执行职责分离 + **前缀不变性测试**：加未来数据不改历史输出 + 口径文档 methodology.md）
- **落地路径**：不引入回测引擎，先做两件事：① 对 R1-R4 候选池与全部截面模块跑 RankIC（用现有 1990 至今年日 K，【推断】抽样近 5 年）；② 把"前缀不变性"立为分析模块验收标准（模块输出只依赖 ≤锚定日的数据）
- **预期收益**：复盘结论从"经验陈述"升级为"带统计显著性的陈述"，与 verifier.py 滚动战绩互补
- **成本**：中高

#### P1-7 选股策略移植（盘后策略 → 截面模块）
- **来源**：`sngyai/Sequoia-X`（7 个纯日K盘后策略：海龟突破+市值排序+反高开低走双层过滤、MA5/20 金叉放量、高窄旗形、涨停洗盘、120 日 RPS≥90）、`myhhub/stock`（61 形态 + 筹码三角 + 停机坪/回踩年线/突破平台等 11 策略 + `check()` 一行注册制）、`ling-0729/KHunter`（五维评分 技术35/资金35/基本面10/板块10/事件10 + **一票否决 VETO=-100 独立于加权** + 大盘 ADX 仓位闸门）
- **落地路径**：挑选 3-5 个策略做成截面模块（依赖现有日 K + 估值 + 资金流数据）；"一票否决"机制可直接强化 R1-R4 排雷
- **成本**：中

#### P1-8 舆情情绪增强

## 八、stock_yuzh 的相对优势（对比中确认，勿妄自薄）

1. **数据资产厚度独一档**：1990 至今年日 K 全覆盖 5820 只 + 复权因子 1667 万行 + 两融/龙虎榜 2019 起 + 财报 34.6 万 + 估值 694 万。129 个项目全部是「实时/近期抓取 + SQLite/Parquet 轻存」（vibe-astock 靠 15:35 快照对抗上游 29 天保留期），没有一个拥有可回算的跨周期数据底座——这是本项目最深的护城河【推断】。
2. **数据质量工程在入库层**：前复权断裂检测/缺行分流/存疑标记，覆盖在入库而非消费层。
3. **截面链确定性可复现**：同锚定日 CSV 逐字节一致 + 黄金样本回归，129 个项目中仅 tick-stock-panel 的 Polars 管线与 Vibe-Research 的 calc 库接近此纪律。
4. **纯盘后静态 = 零误报、零交易合规风险**，天然免疫盘中误报治理与 T+1/费用/风控复杂度。
5. **skill 编排正是「程序算数 + AI 解读」分工的最后一环**，与 FinRobot「models reason, software computes」、Vibe-Trading 数字接地门完全同构——P0-3 的插入成本几乎为零。
