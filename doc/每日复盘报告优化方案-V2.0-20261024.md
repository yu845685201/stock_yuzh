> **函数级实施设计见《每日复盘报告优化-V2.0-技术实现方案-V1.0-20261024.md》**（改动文件全景、代码骨架、测试映射、验收命令、回滚方式）。

## 一、背景与输入

本方案合并三个来源的问题清单，针对每日复盘报告（六维 md + 图文 digest + digest_note 解读 + 缠论小节）做系统性优化：

1. **2026-10-23 digest 第一轮评价**（缠论上线前版本）：报告层 9 项问题——口径不自解释（炸板率三个数关系不明）、情绪判据不透明、次新股混入行业榜、"异动子集"旧文案、操作池指令性表述、黑话不自包含、PC 率归类错位、A50 快照过期误读、资金锚置信度无标注。
2. **2026-10-24 全量代码审计**：10 项业务问题（B1-B10）+ 10 项代码问题（C1-C10），含文件行号定位，均未修复。
3. **2026-10-23 digest 第二轮评价**（缠论小节上线首日重跑版）：8 项新增——缠论候选×存疑清单交叉核对缺失（存疑股票 341→1194 只）、背驰阈值与短笔偏倚未披露、"零互斥首日即成立"过度表述、弱化规则/无二买无解释、digest 固定模板无缠论渲染位、校验脚本缺缠论规则、R 系列候选无先验随行、长窗口完整性预检缺位。

**不动的东西（已验证有效，勿重复建设）**：同一实现两入口（链层与报告层共用规则）+ 逐值对拍机制、三态核验（数据不足≠判错）、"不硬造"原则、2026-10-03 情绪判据校准成果（1149 对样本）、**缠论小节已内置资产**——固定先验注记 HIST_NOTE（`chan_candidates.py:18-23`）、报告×链对拍告警（parity）、同中枢重发标记（refire）、"收盘确认/次日开盘"操作口径注记、背驰强度公式注记。这些是缠论小节写得比老章节规范的根基，后续只在其上补缺，不推倒。

## 二、总体策略

### 2.1 四个修复层次（优先级从高到低）

| 层次 | 回答的问题 | 改动面 |
|---|---|---|
| L1 数据正确性 | 数字本身对不对 | 代码层（改一次长期生效） |
| L2 口径可复核 | 数字对，但读者能不能自己验证 | 报告渲染代码层 |
| L3 表达规范 | 说的方式有没有执行风险 | skill 提示词层（digest_note 每日生成） |
| L4 工程质量 | 快不快、稳不稳 | 代码层 |
| L5 结构增强（可选） | 框架要不要变强 | 代码层，逐项单独授权 |

### 2.2 关键事实（决定方案形态，均经代码核实）

- **digest 结构**：`review/digest.py:build_digest()` 渲染图表与固定段落；"复盘解读"来自 LLM 按 skill 提示词生成的 `digest_note.md` 注入。**L3 类问题改提示词，L1/L2 类问题改代码。**
- **情绪判据已校准**（`config.yaml:138-144`），`_sentiment_cycle` 已产出判据命中明细与分位四态，**digest 只渲染了结论一行——数据在、没展示**（P1-1 成本最低收益最高）。
- **缠论引擎无缺日门控**：`chan/scan.py:97-114` 前置过滤仅有空 df/锚定日无 K/<120 根/NaN 值/非正价/ST 六项，**无"窗口内交易日覆盖"检查**。链窗口 132→520 日后，存疑股票从 341 只翻到 1194 只（Top 原因 2025-2026 单日缺日），这些股票的笔/中枢划分在残缺序列上进行——**假背驰风险未设防**（P0-7 核心）。
- **背驰入选阈值是隐含的**：`chan/signals.py:90` 判据 `abs(a2) < abs(a1)`，即比值 <1 即背驰、无更强门槛；报告按强度升序展示。同时 D2 段必须是已完成笔（分型确认，天然有最小构成规则），但"短笔→柱面积天然偏小→比值趋 0"的偏倚客观存在（回测口径如此、统计已定价）——两者都只需**披露**不需改判定（P1-8）。
- **回补纪律**：改涨停判定（P0-1/P0-2）会改写历史情绪序列与链 CSV。流程：改 → 4 个历史日期 A/B diff → 用户看 diff → 再授权全量回补。

## 四、第 1 批 P0：地基修复（数据正确性，7 项）

> 目标：报告里每个数字本身可信。批内建议顺序：P0-3 → P0-5 → P0-4 → P0-6 → P0-7 →（P0-1 + P0-2 一起做，最后做，因为涉及历史回补决策）。

### P0-1 涨停判定低价股漏判（B1）｜规模 M｜风险中

- **现状**：`THRESHOLD_OFFSET=0.10` 固定偏移法，主板判涨停阈值≈+9.90%。真实涨停价 `round(preclose×1.1, 2)` 对低价股涨幅不足 9.90%（例：preclose 2.04 → 涨停价 2.24 = +9.80%）→ 系统性漏判低价涨停股。
- **影响面**：连板/炸板/溢价/晋级/R1-R3 候选/全部情绪指标——下游全污染。
- **改法**：阈值法改为**精确涨停价比对**：`limit_price = round(preclose×(1+limit_pct), 2)`，`close ≥ limit_price − 0.001` 判涨停。`limit_pct` 按板块取值（主板 10% / 创业板科创 20% / 北交 30% / ST 5%），与 P0-2 的次新特例共用同一序列函数。
- **验收**：单测（低价股 2.04→2.24 命中、各板块边界用例）；4 个历史日期 A/B 重跑出《涨停判定翻转清单》；与 `limit_seal_stats_daily`（分笔自算封板价）交叉对拍。
- **风险与后续**：判定变化改写历史情绪序列。A/B diff 出来后**停住**，用户确认后再进入全量回补（见 8.2）。

### P0-2 次新股无涨跌幅限制期误判（B2）｜规模 M｜风险中

- **现状**：`limit_pct_series` 无 `list_date` 概念，`suppress_first_day` 只挡上市首日。注册制上市第 2-5 日无涨跌幅限制：涨幅 25% 收最高被误判"涨停"、冲高回落被误判"炸板"。
- **改法**：`limit_pct_series` 接 `list_date`：注册制板块上市前 5 个交易日内 `limit_pct=None`（无涨跌幅限制），涨停/炸板判定对该股跳过，情绪分母中不计入。
- **附带修复（评价-3，行业榜"次新股"）**：行业等权榜（`sector.industry_today`）混用 sina_hy 概念板。行业榜仅保留真实行业板；"次新股""ST 板"等概念板若入榜则单独打"概念"标签或移入概念聚集区。
- **验收**：10-23 重跑行业榜无"次新股"以行业身份出现；构造"上市第 3 日涨 25%"用例不判涨停不进炸板分母；A/B diff 纳入 P0-1 同一份报告。

### P0-3 资金锚数据源编排缺失（B7）｜规模 S｜风险低

- **现状**：`hkex_connect`/`etf_scale` 在 `ALL_SOURCES`（`review_sync_orchestrator.py:50`）但不在 `DEFAULT_SOURCES`（34-41 行），`--sources` 显式指定还报"未知源名"；326 行 `return list(DEFAULT_SOURCES)` → 只跑 `sync-review-all` 时两源永远不执行，资金锚恒停旧值。
- **改法**：两源并入 `DEFAULT_SOURCES`；修源名校验（ALL_SOURCES 内源名应被接受）。
- **验收**：`sync-review-all` 后两源快照日期=当日；`--sources hkex_connect` 不报错。**P1-6 的前置。**

### P0-4 VETO 财务前视偏差（C3）｜规模 S｜风险低

- **现状**：VETO 业绩查询无 `as_of`/披露日约束 → 用未来公告否决历史候选，历史报告重跑不可复现。
- **改法**：财务查询统一加 `pub_date <= as_of`（披露日以真实 pubDate 为准，既定结论）。
- **验收**："公告日 > as_of"用例不否决；同一 as_of 两次重跑 VETO 清单完全一致。

### P0-5 核验滚动统计同日双计（C8）｜规模 S｜风险低

- **现状**：`verifier.py:317` 滚动窗口条件含当日 → 同日重跑战绩双计。
- **改法**：改 `trade_date < as_of`。
- **验收**：同日连续重跑两次滚动战绩不变。

### P0-6 行业归属查询不确定（C2）｜规模 S｜风险低

- **现状**：`_sector_money` 混查 `sw_2021`+`sina_hy` 无 ORDER BY，`seen` 取首行 → 行业归属取决于返回顺序，违反"同数据同结果"。
- **改法**：明确优先级（sw_2021 优先，无行再落 sina_hy）+ 稳定 ORDER BY；行业榜与资金归集共用同一归属结果。
- **验收**：同数据多次重跑行业归属逐值一致。

### P0-7 缠论输入数据完整性门控与交叉披露（评二-1）｜规模 M｜风险中【新增】

- **现状**：`chan/scan.py:97-114` 前置过滤仅六项（空 df/锚定日无 K/<120 根/NaN/非正价/ST），**无窗口交易日覆盖检查**。链窗口 132→520 日后存疑股票 341→1194 只（Top 原因 2025-2026 单日缺日、前复权断裂），这些股票照常参与缠论判定——**缺日改变笔/中枢划分 → 假背驰风险**。报告小节与 16 只候选均未与存疑清单交叉披露，"多数不影响当日判定"是笼统断言。
- **改法（两层）**：
  1. **引擎层**：`scan_stock_anchor` 增加交易日覆盖检查——输入序列与市场交易日历对比窗口覆盖率：缺口 >2%（约 >10 天）→ `insufficient("窗口缺日 X%")` 直接不判定；缺口 ≤2% → 保留判定但 detail 标记 `data_flag="缺日N天"`。前复权断裂（复权因子跳变）同规则处理。因"同一实现两入口"，链模块与报告层自动同步。
  2. **报告层**：`chan_candidates.py` 增加与链 meta 存疑清单的交叉——命中存疑的候选在表格加"数据标记"列点名；小节脚注固定输出"本日 N 只候选中 M 只带缺日/断裂标记（已剔除 K 只/打折标注）"。digest 解读层数据质量表同步引用该交叉结果。
- **验收**：构造用例（520 日窗口删中段 3 天 → 标记；删 15 天 → insufficient）；10-23 重跑：16 只一买 × 1194 存疑清单交叉结果写进小节，逐只可见；**回测敏感性说明**——验证项目（2015-2026 全A）若未做同样门控，需在 `data/chan_validation/report.md` 补一节"缺日样本占比与剔除后统计变化"，确认 +6.8%/53.1% 量级不动（预期不动：缺日股占比 ~21% 但一买命中稀疏，实际交集更小）。
- **风险**：门控过严 → 候选变少（可接受，左侧池宁缺毋滥）；若回测敏感性发现统计显著变化，则缠论先验数字需修订并同步 HIST_NOTE——这是本项唯一的结论性风险，必须先于其他缠论增强（P1-8/P4-7）完成。

## 五、第 2 批 P1：口径透明度（让每个数字可复核，8 项）

> 目标：非专业读者拿报告能自己验证每个结论。全部是报告渲染层，不动判定逻辑，可与 P0 并行授权。

### P1-1 情绪判据对照表（评价-2）｜规模 S｜收益最高

- **现状**：digest 情绪节只有"定位：回暖/震荡（未命中判据）"一行（`digest.py:472-475`）。判据、阈值、当日值、分位四态全部已算出但未渲染。
- **改法**：情绪节渲染判据对照表（判据｜阈值｜当日值｜命中）+ 分位标定四态并列展示。10-23 案例：高度 6 板命中高潮半条件、溢价 3.38% 距 4.0% 差 0.62pct——表格直接回答"为什么不是高潮"。
- **验收**：10-23 重跑含完整对照表；阈值与 `config.yaml` 逐值一致；规则四态与分位四态分歧时显式提示。

### P1-2 口径字典（评价-1）｜规模 M

- **现状**：三个"炸板"相关数字来自三个模块无解释：当日炸板率（情绪表）、题材反馈"炸板修复+0.98% 翻红 55%"（`sector_mainline.py:97-106`）、封板质量"首封/开板/一次未炸 49%"（`aggregator.py:1128` 起 F 指标）。
- **改法**：digest 固定渲染折叠式**口径字典**，逐条定义：涨停家数、炸板率（炸板家数/(封板+炸板)）、溢价均值、score（10 日窗口相对读数）、首封、开板、一次未炸、翻红（题材反馈指标）、R1-R3、P1-P3、**一买/二买/背驰/中枢**（缠论术语并入字典，见 P1-8）。
- **验收**：关键术语字典全覆盖；`check_digest_numbers.py` 校验字典条目齐全性。

### P1-3 图注与正文数字格式统一（评价-1）｜规模 S

- **改法**：分位类图注统一"当日值 X%（250 日分位 Y%）"；score 行附"（10 日窗口相对读数，样本小仅作方向参考）"——docstring 已有此口径（`aggregator.py:1063-1067`），报告未体现。
- **验收**：10-23 重跑全图注人工核对格式统一。

### P1-4 死代码与校准水印（C1）｜规模 S

- **现状**：`aggregator.py:1054-1059` 双 return → `trial` 水印永不显示、`sentiment_calibrated` 开关失效。
- **改法**：删第二 return；水印并入首个 return；digest 按 `sentiment_calibrated=false` 标注"判据试用版"。
- **验收**：单测覆盖开关两态。
