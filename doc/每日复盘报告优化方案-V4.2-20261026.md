## 1. V4.1 自我诊断（重制原因）

1. **按实施便利组织，不按读者价值组织**。V4.1 的批次围绕"缓存版本耦合"排布
   （v13 什么和什么同批），读者关心的是"打开页面我能得到什么"。V4.2 按
   **阅读路径三层**组织：10 秒速览层 → 3 分钟主线层 → 深挖层。
2. **按症状开药，不按根因开药**。V4.1 用五条独立规约+WARN lint 分别治括注
   嵌套、池排序、免责重复、工单号、格式漂移——全是 note 无结构契约这一个根因
   的五个症状，靠 agent 每日自律执行。V4.2 以 **note 骨架契约**（固定行格式/
   固定行序/固定去重）根治：违规在结构上不可能发生，lint 降级为兜底保险丝。
3. **两处实质遗漏**：缠论双呈现重复（digest §六固定区已渲染口径/先验/联动五
   要素，note 缠论小节再复述一遍）；要闻采集不在复盘流程内——10-08~10-23
   断档会复发。
4. **速览提取是静默失败契约**。V4.1 D7 靠正则提取 `**主干：…**`，agent 某天
   格式漂移→速览框悄悄退化，无人知晓。且 D4 措辞修复漏了 SKILL.md:368 ③
   自己也在用「距低点第 N 天」。

## 3. 逐项设计（按批次的阅读价值主题分组）

### 批一「打开 10 秒拿到全部结论」（T1 + T2，纯呈现，~1 天）

#### T1 页首三行速览框（硬校验版）

**现状**：digest 信息密度高但无速览入口；主干判断在页面下部解读区。

**改法**：
1. 落点 `digest.py:678-687`（h1 后、口径说明行前）加 `<div class="tldr">`：
   - ① 主干句：从 note 正则提取 `**主干：…**` 独立行，缺则该行省略；
   - ② 关键数一行（零新计算，build 时已有字段，缺失逐项降级）：
     `情绪档 {position} · 空间高度 {梯队最高档} 板 · 涨停 {N} 家 · 溢价均值
     {x}% · 两市 {N} 亿（较昨 {±x}%）`（两市字段依赖批三 T3，先行渲染
     turnover 今/昨两值，T3 落地后自动切 series 末值——同一字段路径）；
   - ③ 转天倾向：note 提取 `**基准倾向**：` 行，缺省回退 `_match_positioning`
     （`tomorrow_plan.py:255-260`，digest import sections 先例 `digest.py:556`）。
2. **硬校验（对 V4.1 的关键升级）**：check 结构规则库（P2-5）追加第 ⑥⑦ 条
   **硬失败**——有 note 时：⑥ 必含 `**主干：` 开头的独立行；⑦ 必含
   `**基准倾向**：` 行。提取失败从"静默退化"变"发布阻断"。
3. note 读取时机前移（`digest.py:878-891` → build 早期读一次，提取后原样装配，
   只装配不加工红线不破——速览框是提取+渲染既有产物）。
4. `_PAGE_CSS` 加 `.tldr` 样式；SKILL.md 补两句提取契约。

**不做**：P 档不入速览——`verification.scenario.triggered` 是次日核验对昨日
预测的判定语义（`verifier.py:137-195`），放速览会误导。

**测试**：提取函数单测（正常/缺 note/多行容错）；速览框降级单测；check ⑥⑦
阻断单测；byte-stable 基线重固。

#### T2 「距窗口最低点第 N 天」措辞去歧义（补齐 V4.1 漏点）

**现状**：字段语义 = days_since_low（`aggregator.py:1389-1395`）＝锚定日距
10 日窗口内 score 最低日的交易日数。现措辞可读成"昨日是低点"（陡 V）或
"低点在窗口首日"（缓修复），方向相反。三个落点：`digest.py:772`（图文）、
`sections/sentiment.py:140`（六维）、**SKILL.md:368 第 12 条③**（规约原文
自用「距低点第 N 天」——V4.1 漏改，agent 会照规约继续写出旧短语）。

**改法**：三处统一 `距窗口 score 最低点已 {N} 个交易日`；N=0 → `今日即窗口
最低点`。

**验收**：回放 10-23 双报告无双读；SKILL.md 规约原文同步。纯文案，不动缓存。

### 批二「3 分钟读完主线，零重复零噪声」（T5 ★核心项 + T4 规约侧，~1 天）

#### T5 note 骨架契约（结构根治，吞并 V4.1 的 D1b/D2/D3/D5）

**现状**：note 由 agent 按 SKILL.md 规约手写，规约是"要求清单"不是"固定
骨架"——五个症状反复发生：括注三重嵌套（note:13）、一句三括注（note:10）、
精选池排序无据（大港 42.9 → 科远 49.1 → 恩捷 71.3，同证据档内分数升序、
最高分垫底，事后核实纯偶发）、免责双份、缠论小节复述 digest §六已有内容。

**改法**：SKILL.md 从规约清单升级为**固定骨架模板**（五条结构规则）：
1. **分解行固定格式**：`维度：读数/结论（来源；来源）`——括注只在行尾一处、
   禁嵌套。嵌套在结构上不可能，不靠"请勿嵌套"自律。接地义务（P0-3①）完整
   保留——固定的是位置与数量上限（每行一处、句内 ≤2 处），不是免除。
2. **精选池行序规则**：照抄六维§六候选表序（证据数 desc → 评分 desc →
   成交额 desc，`tomorrow_plan.py:485-496` 评分序 + 档内规则补充），agent
   只挑选不改序；表头括注「按证据数×评分降序」。与报告表评分优先的差异是
   设计意图（精选池=证据强度优先的严格子集），骨架中写明。
3. **缠论小节瘦身**（=V4.1 遗漏项）：note 缠论节只留解读性内容——无二买
   结构解释、与 R 系列零重叠、【推断】观察项；**口径注记/先验数字/情绪联动
   由 digest §六固定区单一出处承载**（digest.py:562-615 已渲染表格/联动/
   数据质量/口径/HIST_NOTE 五要素），note 不复述。先验数字防幻觉锚点不丢
   ——单一出处反而更强。
4. **工单号禁令**（P2-8 追加）：note 全文（含质量点名表说明列）禁 X/P/A/S
   系列工单编号，溯源一律日期表述（"2026-10-26 起"）。
5. **免责单一出处**：note 不写免责 blockquote，digest 页脚恒带（现有行为，
   规约补明确）。

**lint 兜底（保险丝，WARN 级首发，两周无误报再评估升 hard）**：check 脚本
语汇扫描四条——工单号 `\b(?:X\d+|[PSA]\d{1,2}-\d{1,2})\b`（已核对不误伤
P1-P3/V 系列/R1-R4/A50/CHA50CFD）；嵌套括号 `（[^（）]*（`；note 含
「免责声明」；池表行序对拍（复用 check 既有数字接地架构，对 CSV/报告数据
核对，非散文猜测）。

**红线**：骨架固定的是**形状**（行格式/行序/去重），不是**观点**——综合研判
的判断、池的挑选权、推断标注仍在 agent；这是"只装配不加工"的镜像约束
（装配端不加工、生产端按骨架写）。

**验收**：新 note 逐条对照——分解行每行一处行尾括注；池表首行=证据数最高
且档内分最高；缠论节 ≤4 bullet 无先验数字复述；全文零工单号零免责。

   WARN 首发两周再评估。

   test_skill_copies_in_sync 守护）。
