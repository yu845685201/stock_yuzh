## 二、测试结果

### 2.1 单元测试（pytest）

- **新增 61 个用例**（6 个文件）+ 存量 95 个 = **156 passed, 1 skipped，全部通过**。
- 覆盖方案 §十二-5 要求的关键点：
  - 风控信号识别：403/429/非 JSON 不重试直接 ReviewBlockedError（含冷却值传播）；5xx/网络异常按次数退避重试；`allow_status` 透传（test_review_http_base.py）；
  - 分笔资金流口径：Status 0/1 归向、中性盘 tick-rule（升买/降卖/平价继承、首笔剔除）、未知状态（实测出现 5=盘后定价）归中性、大单阈值、厘→元单位换算、日K成交额缺失不硬造占比（test_money_flow_calc.py）；
  - 断点续跑/幂等：manifest 原子写 roundtrip、除权触发清单合并幂等（test_review_trigger_and_exchange.py）；
  - 公告分类与预告解析：标题分类词表、预告类型、净利润区间（亿元/万元/区间反转）、报告期（test_announcement_classify.py）；
  - THS 解析：flash 行列对齐、中文数字（万/亿）、每股指标×总股本折算（无股本留空）、回填年数、验证码特征识别（test_ths_source.py）；
  - PE/PB 自算：TTM 累计→单季换算（最新年报=累计）、缺上年同期不硬造、股本回退、insufficient_note（test_valuation_calc.py）；
  - 新浪/中证解析：int_/rt_hk_/fx_ 三格式、中证列前缀匹配与结构变更为空防护（test_review_sources_parse.py）。
- 存量测试（日K合并/重检/基本面映射/analysis 全链）无回归。

## 三、部署与运维说明

1. **tdx-api 新接口部署**：因 Docker Hub 不可达，未走镜像重建；使用 go1.22.5（golang.google.cn 下载）交叉编译 linux/amd64 二进制，`docker cp` 注入容器 + `docker restart` 生效。镜像重建时新代码自动纳入（源码已在构建上下文）。新增端点：`GET /api/ths-factor?code=`、`GET /api/xdxr?code=&limit=`。
2. **依赖新增**：xlrd>=2.0.1（中证 .xls 解析），已装入库内 venv 并登记 requirements.txt。
3. **采集执行**：`sync-review-data` 一条命令（支持 `--sources` 子集、`--dry-run`）；周频 concept/unlock 显式指定；源间并发波次并行（parallel_workers=4），各源内部串行限速不变。
4. **待补清单**（报告侧固定标注）：概念板块 4.8、解禁日历 4.12、深交所预约披露（SSE 已覆盖）、pe_ttm（中证官方无此口径）。
