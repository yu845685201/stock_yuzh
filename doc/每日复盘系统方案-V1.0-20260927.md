## 一、复盘框架（按资深稳定盈利股民的方法论设计）

每日复盘回答四个问题：**今天市场怎么样（定仓位）→ 钱在哪些方向（找主线）→ 谁在异动（找标的）→ 明天怎么办（预案）**。报告按六个维度组织：

| 维度 | 核心指标 | 数据来源 |
|---|---|---|
| 1. 大盘环境 | 指数涨跌与位置、两市成交额及增减、上涨/下跌家数、涨停/跌停家数对比 | 指数K线（tdx-api 已支持）+ 全市场日K（已有） |
| 2. 市场情绪 | 连板梯队与空间板高度、炸板率、昨日涨停股今日平均溢价、晋级率、亏钱效应 | 全市场日K（已具备） |
| 3. 板块主线 | 行业涨跌榜（今/5日）、板块涨停聚集度、主线识别、高低切换观察 | 日K + 行业分类（已具备）；概念题材待补 |
| 4. 个股异动 | 涨停/跌停明细、放量大涨、60日新高新低、换手率异常 | 全市场日K + 股本（已具备） |
| 5. 业绩估值 | 财报披露日历、业绩预增/超预期、增速与估值排序 | 免费渠道财报（待同步）；个股 PE/PB 自算 |
| 6. 结论预案 | 情绪周期自动定位（冰点/回暖/高潮/退潮）、明日关注、风险提示、免责声明 | 由前五维计算 |

## 二、实现方案（基于 stock_yuzh 现有架构，不动 tdx-api）

沿用"逐股分析模块 + 链引擎"模式，新增**报告聚合层**。

### 阶段 1：现有数据 + tdx-api 补指数K线（首先实施）

1. `doc/复盘框架.MD` — 各指标定义、计算口径、解读方法（复盘教材 + 开发验收依据）。
2. **新增分析模块**（`backend/src/analysis/modules/`，遵守 module_base 规范：纯函数、向量化、pytest、登记 README）：
   - `limit_down_today` 跌停
   - `burst_limit` 炸板（盘中触板未封住）
   - `limit_up_premium` 昨日涨停今日溢价
   - `big_mover` 大涨大跌标记
   - `volume_surge` 放量倍数（当日量 / 5日均量）
   - `new_high_low` 60日新高新低
   - 复用现有 `limit_up_today`、`consecutive_limit_up`；涨跌停阈值沿用 `limit_up_rules.py`（主板10% / 创业板科创板20% / 北交所30% / ST 5%）。
3. 新链 `chains/daily_review.yaml` 串起全部模块（lookback 60 交易日）。
4. **报告生成器**（新包 `backend/src/review/`）：
   - 聚合层：市场宽度截面统计（SQL/pandas）、行业板块聚合、情绪指标计算；
   - 渲染层：MD 为源，输出 `doc/reports/daily_review_YYYYMMDD.md` + 同名 `.html`（轻量模板、内联 CSS，无外部依赖）；
   - 缺数据章节明确标注"待补"而非留空（符合项目数据真实性原则）。
5. CLI：`run_cli.py review generate [--as-of yyyyMMdd]`。每日流程：盘后 sync 数据 → `review generate` → 读报告。
6. **指数同步脚本**：调 tdx-api `/api/index/all` 拉取上证指数、深证成指、创业板指、科创50、北证50、沪深300 全历史 → 入库已建好的 `trade_index_info` 表。

### 阶段 2：财报数据（免费渠道同步后）

- 新增 `base_financial_report` 表 DDL → 同步财报指标（营收/净利/同比/ROE/毛利率/现金流/EPS，5年全市场季频）→ 披露日历、业绩预增、增速排行模块与报告章节。
- 个股 PE/PB 自算：市值 = 收盘价 × 总股本（`base_fundamentals_info` 已有）；PE(TTM) = 市值 ÷ 近四季归母净利；PB = 市值 ÷ 净资产。
- 指数 PE 取中证指数官网日频。

### 阶段 3：概念/龙虎榜/资金流数据到位后

概念题材聚合（涨停潮识别）、龙虎榜席位、资金流向、两融章节。

## 三、缺失数据清单及来源（全免费）

### 3.1 tdx-api 现有能力核实结果

- ✅ **指数日K线**：`/api/index`、`/api/index/all` 已可用 → 同步入 `trade_index_info` 表（上证指数 sh000001、深证成指 sz399001、创业板指 sz399006、科创50 sh000688、北证50 bj899050、沪深300 sh000300；北交所代码实现时验证）。
- ✅ **复权因子**：协议库含 `model_xdxr`（除权除息）、`ths-factor.go`（同花顺因子）→ 可修复现有"历史前复权断裂"问题。
- ⚠️ **主力资金流近似**：无现成接口，但 `/api/trade-history` 分笔带买卖方向（Status 0买/1卖/2中性）+ 单笔量额 → 可按单笔金额分桶自算"大单净流入"近似值（自定口径，免费，唯一不花钱的路径）。
- ❌ 无财务、板块、龙虎榜、两融、解禁、公告接口（协议库仅有 F10 常量，未实现）。

### 3.2 逐项来源规划（全部免费）

| 数据 | 首选来源 | 兜底 | 说明 |
|---|---|---|---|
| 指数日K线 | **tdx-api** ✅ | — | 已有接口，写同步脚本即可 |
| 复权因子 | **tdx-api** ✅ | — | xdxr 模型 |
| 结构化财报指标 | **Tushare 免费积分档**（注册赠送积分即可，60分门槛接口不花钱） | 同花顺个股财务页 | 免费档有频率限制，首次全量同步慢（一次性成本），每日增量没问题；同花顺有 spider-ths 先例可复用 |
| 财报披露日历 | **沪深交易所官网**预约披露页 | Tushare 免费档 | 官方一手 |
| 业绩预告/快报 | **巨潮资讯网**公告检索 | Tushare 免费档 | 官方一手 |
| 个股 PE/PB | **自算**（财报+股本+收盘价） | — | 不依赖外部源 |
| 指数估值 PE | **中证指数公司官网**每日发布 | 上交所/深交所官网市场 PE | 官方一手 |
| 概念板块成分 | **同花顺概念页** | 通达信客户端板块文件（T0002/hq_cache） | tdx-api 已有 spider-ths 同花顺爬虫先例，工程模式可复用 |
| 龙虎榜 | **沪深交易所官网披露页**（每日盘后官方 JSON） | 同花顺龙虎榜页 | 官方一手最稳 |
| 主力资金流 | **tdx-api 分笔自算**（金额分桶×买卖方向） | — | 近似口径，免费路径唯一 |
| 融资融券 | **沪深交易所官网每日披露** | — | 官方一手 |
| 解禁日历 | **同花顺解禁数据页** | 巨潮逐份公告解析 | 最难免费拿的一项，优先级最低，可最后补 |
| 公告/新闻 | **巨潮资讯网**（官方公告一手，反爬宽松） | 同花顺个股资讯页 | 盘后公告清单 |
| 外围市场（美股三大指数/汇率） | **新浪财经裸 HTTP**（全球指数/汇率接口，反爬松） | — | 轻量 |

**来源优先级**：① tdx-api（指数、复权因子、分笔）→ ② 交易所/中证/巨潮官网（官方一手）→ ③ 同花顺（已验证的爬虫先例）→ ④ Tushare 免费积分档（仅财报类低门槛接口，不花钱）→ ⑤ 新浪（外围轻量）。

Tushare 付费接口（龙虎榜/资金流/两融/解禁/概念等高积分项）**全部不用**。

## 四、验收标准

1. 盘后一条命令生成当日 MD+HTML 复盘报告，现有数据可支撑的章节全部呈现，缺数据章节明确标注"待补"；
2. 全部新模块 pytest 通过并登记 `src/analysis/README.MD`；
3. 报告含数据口径说明与免责声明；每个新数据源配同步报告（沿用现有 sync report 模式）；
4. 不改动 tdx-api 代码，不引入 akshare/baostock/东财，不使用任何付费数据。
