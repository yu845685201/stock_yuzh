## 二、新发现详述

### X-13 🟠 申万二级行业成分下载受阻（G 项需专项解决或降级）

**已验证可行的部分**

- 清单接口直接支持 `indextype=二级行业`：**134 个**二级（翻页 50/页 × 3 页抓全），每项含 `{id: GUID, swindexname}`；
- 一级行业的成分下载路径此刻完全正常（`download_file/?file_name=农林牧渔分类表` → HTTP 200，xlsx 8,310 字节）——**排除临时风控/接口故障**。

**受阻的部分（多路径实测）**

| 尝试 | 结果 |
|---|---|
| `download_file/?file_name={二级名}分类表`（如"农产品加工分类表"、"林业Ⅱ分类表"） | **HTTP 500**（罗马数字非因素：无特殊字符的名称同样 500） |
| `file_name` 变体（无"分类表"后缀 / 加 .xlsx / 带Ⅱ） | 全部 500 |
| `download_file/?id={清单返回的GUID}` | HTTP 500 |
| 官网"全部行业分类下载"接口 `all_trade_classification_download/`（umi.js 中实锤存在） | 301→302 链，最终落回首页 HTML——**需会话状态**，curl 纯 HTTP 无法复现 |
| 浏览器实测（IAB 实开页面） | 行业分类下拉为虚拟过滤组件（无原生 select）；"全部行业分类下载"点击后无新增网络请求可捕获（页面用 blob/独立下载通道）；SPA 主 bundle（1.3MB umi.js）中下载函数参数 `t` 的构造在路由 chunk 中，未逆向到 |

**对 G 项的影响**：方案 §4.7 设计"`fetch_industry_members` 参数化 indextype"——清单可参数化，但**成分下载不能复用一级管道**。没有成分映射，二级行业榜（等权涨跌幅）无法计算。

**备选方案（待用户选择）**：

1. **专项逆向**（约 0.5 人日）：加载行业分类页面的路由 chunk（umi 按需分包），找到二级下载的真实参数/接口；或用 playwright 带完整会话态批量触发 134 个下载。可行但工程脆弱度高；
2. **G 项降级**：仅接入二级行业**清单与行情**（134 个行业指数若有行情源），放弃成分映射 → 行业榜退化为行业指数涨跌榜（需另探行业指数行情源，申万指数官网已失效）；
3. **G 项延后**：Phase C 先做 B/E/F，G 挂起待逆向结论。

### F 项试算记录（含一个重要口径发现）

**四只涨停股实算（20260930，F 项验收口径预演）**：

| 股票 | 形态 | 分笔max vs 理论涨停价 | 首封 | 开板 | 封住占比 |
|---|---|---|---|---|---|
| 600825 新华传媒 | 一字 7 板 | 10.35 = 10.35 ✓ | 092500 | 0 | 100% |
| 000692 惠天热电 | 开板回封 | 4.59 = 4.59 ✓ | 094200 | 4 次 | 86.5% |
| 600059 古越龙山 | 开板回封 | 12.27 = 12.27 ✓ | 093100 | 4 次 | 96.0% |
| 002226 江南化工 | 开板回封 | **5.34 ≠ float 口径 5.33** | 100500 | 2 次 | 68.6% |

**江南化工的"不一致"实为重要发现**：preclose=4.85，交易所涨停价 = 4.85×1.1 = 5.335 **十进制四舍五入 = 5.34**；Python 浮点 `round(4.85*1.1, 2) = 5.33`（5.335 的浮点存储为 5.33499...）。分笔 max=5.34 与交易所口径一致——

> **结论：文档 §4.6 "limit_price = max(分笔成交价)" 的设计不仅绕开复权陷阱，还同时绕开了浮点舍入陷阱**。
> 实施红线：F 项任何需要"理论涨停价"的对照（如验收核对）必须用 `Decimal ROUND_HALF_UP`，禁止 float round；
> sealed 判定坚持用分笔 max 口径（文档设计），不要改成理论价口径。

算法侧 first/last/open_count/sealed_ratio 在一字板与开板回封两种形态下输出均符合语义（四股 first_seal_time 全部落在 09:25~15:00，验收口径满足）。
