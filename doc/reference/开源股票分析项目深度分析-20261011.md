## 一、LLM / 多智能体股票分析框架

这一类项目以「大语言模型驱动的多智能体协作」为核心范式，把传统券商/私募内部"分析师—研究员—交易员—风控"的组织分工映射到 LLM Agent 角色上。**数据源方面**呈现明显的中外分化：面向美股/全球市场的项目（TradingAgents、FinRobot、LangAlpha、ai-financial-agent 等）普遍依赖 Yahoo Finance / Alpha Vantage / Finnhub / FMP / SEC EDGAR 等英文 API，而 A 股项目（daily_stock_analysis、TradingAgents-CN/astock/AShare、aiagents-stock、WyckoffTradingAgent、BreadFree-Simu 等）几乎都围绕 akshare、tushare、baostock、通达信（mootdx/pytdx）、东方财富、新浪财经、同花顺问财、财联社构建多源降级链路，并叠加新闻搜索（Tavily/SerpAPI/Bocha/Brave）与社交舆情（Reddit/StockTwits/微博/雪球）。**架构方面**高度趋同：LangGraph 或 AutoGen 等图编排框架承载"分析师团队并行作业 → 多空研究员辩论 → 研究经理裁决 → 交易员出方案 → 三方风控辩论 → 组合经理终审"的多级流水线，不少项目引入 quick/deep 双 LLM 分层、结构化输出、决策记忆与回测/绩效回填。**产物方面**则以结构化 Markdown/HTML 投研报告（含评级、目标价、风险点、催化剂）、Web/CLI 决策仪表盘、IM 推送（企微/飞书/钉钉/Telegram/Discord）和回测净值曲线为主，少数项目（QuantDinger、ValueCell、AI-Trader）进一步打通真实券商/交易所接口走向"准实盘"。

### [TradingAgents](https://github.com/TauricResearch/TradingAgents)（⭐约110k）
- **项目简介**：Tauric Research 出品的开源多智能体 LLM 金融交易框架（arXiv:2412.20138），模拟真实交易公司的部门协作与辩论机制，是该领域的"源头项目"，后续大量 fork/中文版均以此为蓝本。
- **数据源来源**：Yahoo Finance（行情与公司新闻，覆盖美股/港股/日股/伦敦/印度/加澳/沪深 .SS/.SZ/加密货币）；Alpha Vantage（行情与基本面，含 look-ahead 过滤）；SEC EDGAR（财报三表 filed 原文）；Finnhub（内部人交易、新闻）；Reddit 与 StockTwits（社交舆情，可选 TypeSafe Jev 做帖子过滤）；FRED（宏观经济数据）；Polymarket（预测市场情绪）。
- **分析逻辑**：基于 LangGraph 构建图编排，角色分四层：**Analyst 团队并行作业**——Fundamentals Analyst（基本面/财务红旗）、Sentiment Analyst（新闻标题+StockTwits+Reddit 聚合情绪）、News Analyst（全球新闻+宏观指标）、Technical Analyst（MACD/RSI 等技术指标）；**Researcher 团队**——Bullish/Bearish 研究员对分析师报告做结构化多空辩论（可设 max_debate_rounds）；**Trader Agent** 综合各方产出交易时机与仓位；**Risk Management 团队**（Aggressive/Conservative/Neutral 三方风险辩论）+ **Portfolio Manager** 最终批准/否决订单后送模拟交易所执行。支持 quick_think_llm / deep_think_llm 双模型分层、LangGraph checkpoint 恢复、持久化决策日志与反思、point-in-time 回测（按日期网格、无未来函数）、portfolio-aware 运行。
- **最终产物**：结构化 Markdown 投研报告（各分析师分项报告、辩论记录、交易计划、五档评级 BUY/OVERWEIGHT/HOLD/UNDERWEIGHT/SELL），v0.6 起可导出 `complete_report.html` 单页报告；CLI 实时进度界面；决策日志与回测绩效（对比各市场基准 alpha）。
- **技术栈**：Python 3.11+，LangGraph；LLM Provider 覆盖 OpenAI/Gemini/Claude/xAI/DeepSeek/Qwen/GLM/MiniMax/OpenRouter/Mistral/Kimi/Groq/NVIDIA NIM/Azure/Bedrock/Ollama；Docker Compose 部署。
- **备注**：生态最成熟、迭代极快（2026 年每月都有版本），但面向英文/美股语境，A 股体验需用下游 fork。

### [daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis)（⭐约66k）
- **项目简介**：LLM 驱动的多市场自选股智能分析系统（A股/港股/美股/日股/韩股/台股/ETF），主打"每日自动分析 + 决策仪表盘推送"，GitHub Actions 零成本运行。
- **数据源来源**：行情——TickFlow、AkShare、Tushare、Pytdx（通达信）、Baostock、YFinance、Longbridge（港美）；新闻搜索——Anspire、SerpAPI、Tavily、Bocha（博查）、Brave、MiniMax、SearXNG 自建；社交舆情——Stock Sentiment API（adanos.org，Reddit/X/Polymarket，仅美股）；另有公告、基本面辅助数据与主力资金流向。
- **分析逻辑**：单股分析走"数据聚合 → LLM 综合研判"管线，输出评分（0-100）、趋势（看多/震荡/看空）、买卖点位、风险警报与利好催化；内置 **Agent 策略问股** 模块，提供均线金叉、缠论、波浪理论、多头趋势、热点题材、事件驱动、成长质量、预期重估等 15 种内置策略，支持多轮追问、自定义策略文件与多 Agent 编排（实验性）；带大盘复盘（指数、涨跌家数、涨跌停、板块领涨/领跌）与回测、持仓管理模块。
- **最终产物**：「决策仪表盘」推送——核心结论、评分、趋势、买卖点位、风险警报、催化因素、操作检查清单，推送至企业微信/飞书/Telegram/Discord/Slack/邮箱；Web/桌面工作台提供完整 Markdown 报告、历史报告、回测结果与持仓视图。
- **技术栈**：Python 3.10+，FastAPI（Web 服务）+ Web 前端，Docker 与 GitHub Actions 定时任务，支持 Anspire/AIHubMix/Gemini/OpenAI 兼容/DeepSeek/通义千问/Claude/Ollama。
- **备注**：工程化程度极高（CI、Docker Hub、桌面端打包），文档体系完整（full-guide、market-support、LLM_CONFIG_GUIDE），是中文圈"日报型"项目的代表作。

### [Vibe-Trading](https://github.com/HKUDS/Vibe-Trading)（⭐约35k）
- **项目简介**：HKUDS（港大数据科学实验室）出品的"个人交易智能体"，pip 一键安装，把自然语言策略/研究问题直接跑成代码、回测与实盘连接，覆盖 A 股/港美/加密/期货/外汇。
- **数据源来源**：约 24 个行情加载器自动回退——A 股走 Tushare/Baostock/AkShare/东方财富，港股走腾讯财经，美股走 yfinance/Finnhub，加密走 OKX/Binance/CCXT，期货外汇含 MetaTrader 5；券商连接器达 18 家（IBKR、Robinhood、Alpaca、Binance、OKX、KIS、Upbit、Toss、Scalable Capital 等）。
- **分析逻辑**：核心是持久化 **Research Goals**（跟踪论断、证据、验收标准）+ Agent 写代码取数并执行研究；回测体系为 **7 个市场引擎 + CompositeEngine 跨市场组合引擎**（A股/港美股/加密/中国期货/外盘期货/外汇/期权组合），含 walk-forward、Monte Carlo、Sortino/Sharpe 等指标；v0.1.16 引入 **grounding gate**——模型必须为每个数字声明角色（observed/derived/proposed/cited/count），与会话内工具证据核对，不合格数字被剔除而非整段拒答；支持 Slack/Discord/飞书/Telegram/Email/WebSocket 通道、定时报告、影子账户（Shadow Account）与 MCP 工具暴露。
- **最终产物**：回测报告（JSON/Markdown/Run Detail，含哈希化执行记录与 metric-to-CSV 引用校验）、定时邮件 PDF（可选 AES-256 加密）、可导出至 TradingView/通达信/MetaTrader 5 的结果、实盘订单（可选开启）。
- **技术栈**：Python 3.11+，FastAPI 后端 + React 19 前端 + Rich CLI/TUI，PyPI 包 `vibe-trading-ai`，REST/MCP 双接口。
- **备注**：迭代极其密集（2026 年 9-10 月几乎日更），工程严谨度（数据正确性、look-ahead 防护、CJK 支持）在同类中突出。

### [AI-Trader](https://github.com/HKUDS/AI-Trader)（⭐约22.7k）
- **项目简介**：HKUDS 出品的"Agent 原生交易平台"，口号是"像人类有交易平台一样，AI Agent 也需要自己的平台"——任意 AI Agent 读一段 SKILL.md 即可注册进平台进行交易协作。
- **数据源来源**：美股价格优先 Alpha Vantage，缺失/限流时自动回退 yfinance；Polymarket 预测市场（真数据+模拟撮合）；市场情报（market-intel）后台任务；对接 Binance、Coinbase、Interactive Brokers 等券商做信号同步。
- **分析逻辑**：不是传统的"内部分析师辩论"，而是**平台化集体智能**：Agent 通过 `skills/ai4trade`、`skills/copytrade`、`skills/tradesync` 三个技能接入，发布三类信号——Strategies（讨论型策略）、Operations（可跟单操作）、Discussions（协作讨论）；平台侧做实验/挑战赛（experiment/challenge）进度跟踪、月度挑战、按 leaderboard 相同的 live mark-to-market 评分；一键跟单复制头部 Agent 仓位；积分奖励系统激励发信号与涨粉。
- **最终产物**：Live Trading Platform（ai4trade.ai）网页端——信号流、Dashboard 统一控制中心（/financial-events）、实验控制台、排行榜、跟单仓位；$100K 模拟盘；自托管可选 PostgreSQL/SQLite。
- **技术栈**：FastAPI 后端 + React 前端，OpenAPI 规范（docs/api/openapi.yaml、copytrade.yaml），Skill 文件驱动的 Agent 集成（兼容 OpenClaw、nanobot、Claude Code、Codex、Cursor）。
- **备注**：定位独特——不是单机分析框架而是"Agent 交易的社交平台"；与 Vibe-Trading 互为姊妹项目。

### [FinGPT](https://github.com/AI4Finance-Foundation/FinGPT)（⭐约21.4k）
- **项目简介**：AI4Finance 基金会的开源金融大模型项目，定位为"金融版 LLM 生态"，覆盖数据工程、微调（LoRA/RLSP）、情绪分析、新闻驱动预测与 Agent 应用，是该领域学术影响力最大的项目之一。
- **数据源来源**：依托子项目 **FinNLP** 统一接入 30+ 数据提供商——金融新闻（Yahoo Finance、Reuters、SeekingAlpha 等）、社交媒体（Twitter/X、Reddit、StockTwits、微博）、监管文件（SEC EDGAR filings）、财报电话会纪要、研报数据集；行情侧接 Yahoo Finance、Alpaca、CCXT、Binance、Tushare 等。
- **分析逻辑**：四层架构——Data Source（多源异构数据）→ Data Engineering（FinNLP 清洗、特征工程、prompt 构造）→ LLMs（基座模型 + LoRA 低秩微调，支持 LLaMA/ChatGLM/Falcon/Bloom/Qwen 等）→ Applications。**FinGPT-Forecaster**：输入最近 N 周新闻 + 公司基本信息 + 可选财务指标，输出未来一周股价走势判断（positive/negative/neutral）与分析理由，用对应股价涨跌幅作标签微调；**FinGPT-Sentiment**：新闻情绪三分类；**FinGPT Agents**：fingpt_forecaster、annual_report、trade_strategist 等教程级 agent。
- **最终产物**：微调后的金融 LLM 权重（HuggingFace 上开放）、周度股价预测报告（含理由）、情绪标签、年报复述 PDF、交易策略代码；以及配套基准评测。
- **技术栈**：Python，PyTorch + PEFT/LoRA + Transformers；FinNLP 数据管线；Streamlit demo；与 FinRL、FinRobot 同属 AI4Finance 生态可串联成量化研究流水线。
- **备注**：偏"模型与数据底座"，不是开箱即用的分析产品；学术引用高，适合作为训练金融垂直模型的起点。

### [ai-berkshire](https://github.com/xbtlin/ai-berkshire)（⭐约16.7k）
- **项目简介**：价值投资研究框架，把巴菲特、芒格、段永平、李录四位大师的方法论系统化为一组 Claude Code / Codex Skills，"一个人 + Claude Code = 一个投研团队"，作者公布实盘 2024 +69.29%、2025 +66.38%。
- **数据源来源**：以 LLM 联网检索为主（各 Agent 独立搜索网络、交叉验证），辅以精确计算工具 `tools/financial_rigor.py`（市值手算校验、decimal.Decimal 精确十进制、关键数据≥2 独立来源交叉验证、误差>1% 告警）；不接传统行情 API，定位为"研究 Skill 合集"而非数据管道。
- **分析逻辑**：三层架构——**Skill 层**（20 个入口：深度研究、财报分析、行业筛选、持仓管理、思维工具五大类）；**Agent 层**：`/investment-team`、`/earnings-team` 等团队型 Skill 由 Team Lead 并行调度 4 个大师视角 Agent（段永平=商业模式、巴菲特=财务估值、芒格=逆向思考、李录=长期确定性），各自独立搜索、独立判断、互相挑战后由 Team Lead 综合；**工具层**负责精确计算与报告抽检。反偏见机制完整：信息丰富度 A/B/C 评级、芒格式逆向检验（"什么情况下公司会死"列 5 大情景及概率）、8 条红线一票否决清单、反共识检查（"聪明人为什么做空"）、留白原则（数据不足标注灰色地带）；输出强制给结论：通过/不通过/灰色地带 + 分层价格区间。
- **最终产物**：结构化中文投研报告（能力圈/好生意/护城河/管理层/安全边际五星评分表、综合分、分层建仓建议），`reports/` 目录沉淀 2370 份报告、109 家公司、23 个专题；可横向对比（同标准 Checklist 多公司打分表）；`/earnings-team` 产出公众号级可发布文章（作者/编辑/读者三 Agent 协作）。
- **技术栈**：纯 Markdown Skill 定义（`skills/*.md` 为 Claude Code commands，`codex-skills/*/SKILL.md` 由脚本同步生成），Python 工具脚本，依赖 Claude Code 或 Codex 客户端。
- **备注**：形态独特——不是独立运行的系统而是"Prompt 工程 + 工作流"资产库，零部署成本，强调决策纪律与可复现性。

## 四、量化研究 / 回测框架 / ML 预测

本章节聚焦「量化研究、回测框架与机器学习预测」三大主题，覆盖从经典事件驱动回测到现代向量化批量运算、从传统技术指标到深度学习与强化学习的完整谱系。回测引擎大体可分为两类：**事件驱动（Event-Driven）**框架逐根 K 线/逐笔 tick 模拟交易决策与撮合，适合精细模拟滑点、订单簿与复杂资金管理的策略；**向量化（Vectorized）**框架利用 NumPy/Pandas/Numba 对整个时间序列一次性运算，适合大规模参数寻优与因子研究。数据层方面，多数项目内置 Yahoo Finance、AKShare、RQData、券商 API 等连接器，或提供标准化的 DataFeed/DataSource 抽象接口；产物端则以回测绩效报告（tearsheet）、净值曲线、交易清单、模型权重与预测分数为主流输出形式。

### [qlib](https://github.com/microsoft/qlib)（⭐约49k）
- **项目简介**：微软开源的 AI 原生量化投资平台，覆盖数据准备、因子挖掘、模型训练、组合优化、回测与在线部署的全链路，定位为「从研究到生产」的量化操作系统。

- **技术栈**：Python 3.8+，核心依赖 PyTorch、LightGBM、NumPy、pandas、scikit-learn；C++ 底层加速数据读取；支持 pip（`pyqlib`）与 conda 安装。

### [backtrader](https://github.com/mementum/backtrader)（⭐约23.4k）
- **项目简介**：2015 年发布的 Python 事件驱动回测与实盘交易框架，以高度模块化和灵活性著称，被誉为 Python 量化社区「最经典」的回测引擎之一。

## 六、舆情 / 市场情绪 / 新闻分析

本类别关注「非行情数据」驱动的一类分析项目：从社交媒体、新闻头条与全网热榜中提取情绪与事件信号，用于理解或预测市场行为。其数据源多为 Twitter/X、东方财富股吧、路透社新闻、各平台热搜榜等文本流，核心方法是情感分析（VADER、TextBlob、BERT 微调）与事件驱动建模（贝叶斯 CNN、LSTM），近两年的明星项目（TrendRadar、BettaFish）则代表了大模型时代的新范式——以关键词监控、多 Agent 协作与 LLM 报告生成取代传统词典法情绪打分。对股票分析而言，这类项目通常输出情绪指数、热点报告或涨跌预测标签，作为量价因子的补充维度。

- **最终产物**：Skill 文件 + 内嵌 Python，返回 pandas DataFrame；例如 CBOE 期权链返回含行权价、到期日、买卖价、IV、Greeks、0DTE 标志的 DataFrame；EDGAR screener 可一次性按任意 XBRL tag 筛选全市场（如 CY2025Q1 净利润覆盖 5,309 家公司）。

## 八、投研终端 / 综合平台

本类别项目不再满足于「提供数据接口」，而是把数据、分析、AI 与交易整合成完整的投研工作台。架构上呈现三种主流形态：**数据编排层**（OpenBB 把多源数据标准化为统一 ODP 接口）、**桌面终端**（Fincept Terminal 用 C++20/Qt6 打造类 Bloomberg 的本地化投研环境）、**AI 智能体编排器**（OpenAlice 与 stockbot-on-groq 让 LLM 直接调用行情、研报与交易工具）。共同趋势是：数据获取被抽象为可插拔的 Provider，AI Agent 成为新的交互入口，而「个人 Bloomberg」的愿景正在开源社区逐步实现。

Awesome 类索引是量化投研开源生态的「目录层」：它们本身不产生分析能力，而是按主题把散落在 GitHub 与各语言的库、数据源、策略、论文、课程系统化编目，是定位具体工具的起点。本类别 4 个项目各有侧重——awesome-quant 是最全面的多语言量化资源总目（3 万 star）；awesome-systematic-trading 聚焦「系统化交易」全链路（回测/实盘/Alpha/券商 API）；Awesome-Quant-Machine-Learning-Trading 专攻 ML 量化文献与代码；quant-wiki 则是 LLMQuant 社区维护的中文量化百科，承担汉化与入门教育职能。对中文读者，建议以 quant-wiki 学概念、以 awesome-quant 查工具、以 awesome-systematic-trading 搭系统、以 QMLT 追论文。

### [awesome-quant](https://github.com/wilsonfreitas/awesome-quant)（⭐约30k）
- **收录范围**：量化金融领域最知名的资源总目，收录数百个条目（仅 GitHub 链接即 300+），每个条目标注语言标签（Python/R/Julia/C++/C#/Java/Scala/Rust/JS 等）并附一句话说明，近年还开始收录 MCP 类新工具。
- **分类结构**：按技术栈与职能两级组织——Numerical Libraries & Data Structures（numpy/pandas/polars/xts/data.table 等基础件）；Financial Instruments & Pricing（QuantLib 系 PyQL、vollib 期权定价等）；Technical Indicators；Trading & Backtesting（规模最大的板块，约 150 条，含 backtrader、zipline-reloaded、vectorbt 等）；Portfolio Optimization & Risk Analysis（PyPortfolioOpt、Riskfolio-Lib）；Factor Analysis；Sentiment Analysis & Alternative Data；Time Series Analysis；Market Data & Data Sources（yfinance、akshare、tushare 等百条级数据接口目录）；Prediction Markets；Calendars & Market Hours；Visualization；Excel & Spreadsheet Integration；Quant Research Environments；Cross-Language Frameworks；Reproducing Works, Training & Books（论文复现与书籍）；Commercial & Proprietary Services；Historical & Archived Projects；Related Lists。
- **覆盖资源类型**：开源库为主，兼及数据源 API、研究环境、商业服务、书籍课程与已归档历史项目。
- **使用建议**：想找「某语言 + 某职能」的库时先查此表；条目偏工具级、更新勤快，适合作为技术选型底册。无代码本体，纯 Markdown 列表。

### [awesome-systematic-trading](https://github.com/wangzhe3224/awesome-systematic-trading)（⭐约5.3k）
- **收录范围**：聚焦「系统化交易」全链路的精选清单（GitHub 链接约 270+），覆盖股票、加密、期货、期权、CFD、外汇；中英双语维护，中文名「量化交易/量化投资」。
- **分类结构**：贴近实盘工程的流水线式编目——AI Powered Systematic Trading Systems（LLM 驱动交易系统，新增板块）；Backtest + live trading（通用框架 / 加密专用 / ML·RL 强化学习导向三分支）；Alpha Collections（通用 Alpha、表达式 Alpha、选股、订单簿、加密套利五个子类）；Basic Components（基础金融库、计算加速、Python 性能工具与 profiler）；Analytic tools（指标/定价/风险/组合优化/时序分析）；Visualization；Message Queues；Databases；Data Source（股票与通用 / 另类数据 / 加密 / 预测市场四分）；Broker APIs（券商接口）；Quant Shops Code and Blog（知名量化机构的开源与博客）；Resources（研究、书籍、博客、教程、课程）。
- **覆盖资源类型**：以「能跑起来的系统与组件」为导向，兼顾数据、执行与学习资源；对想从回测走到实盘对接券商的读者，其 Data Source + Broker APIs + Backtest 三段组合尤其有用。

### [Awesome-Quant-Machine-Learning-Trading](https://github.com/grananqvist/Awesome-Quant-Machine-Learning-Trading)（⭐约4.0k）
- **收录范围**：量化/算法交易资源清单中「偏机器学习」的一支，外部链接约 125 条，重文献与代码实践。
- **分类结构**：Books（《Advances in Financial Machine Learning》等 ML 金融书目）；Online series and courses；Youtube videos；Blogs and content websites；Interviews（量化从业者访谈）；Papers（约 40 篇核心文献，López de Prado 系列、Gordon Ritter《Machine Learning for Trading》、Deep Portfolios、LSTM/GRU/GAN/强化学习股价预测等，星标为重点推荐；下设 Events & Sentiment trading 子类）；Reinforcement Learning environments（RL 交易环境）；Code（约 30 个可运行仓库，如 mlfinlab、pairs-trading-with-ML、qtrader、stock_market_reinforcement_learning、deep-algotrading 等）。
- **覆盖资源类型**：书、课、视频、博客、访谈、论文、代码七类，论文与代码占比最高。
- **备注**：编目止于 2018–2019 年前后的文献高峰期，近年更新较少，适合补 ML 量化的经典基础而非追最新进展。

### [quant-wiki](https://github.com/LLMQuant/quant-wiki)（⭐约4.3k）
- **收录范围**：LLMQuant 社区维护的开源中文量化百科（MkDocs 站点 quant-wiki.com），目标是「量化知识的开源与汉化，打破国内外信息差」，定位类似量化界的 OI Wiki（项目方明确致谢其启发）。
- **分类结构**：按知识体系而非工具编目，导航含 11 个一级板块——简介（关于/参与/FAQ）；基本概念（金融术语中英对照：市场与交易、金融工具、交易机制、投资理论、经济指标等词条）；入门教程；学术论文；量化前沿；量化百宝箱（工具资源）；AI+量化；量化图书馆；行业内幕；求职专区；独家资源。
- **覆盖资源类型**：知识词条 + 教程 + 论文导读 + 工具索引 + 求职与行业内容的复合型百科，词条普遍中英双语命名（如「有效市场假说_Efficient Market Hypothesis」）。
- **使用建议**：中文初学者建立概念框架的首选入口；CC BY-NC-SA 4.0 协议（非商业使用限制需注意），支持 `mkdocs serve` 本地部署，接受社区贡献。
