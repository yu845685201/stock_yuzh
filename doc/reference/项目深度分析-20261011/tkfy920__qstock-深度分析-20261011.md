## 0 定位与使用形态

qstock 是「Python金融量化」公众号作者张金一开发的**个人量化投研分析库**，PyPI 可 `pip install qstock`。定位为把东方财富、同花顺、新浪等公开数据「简洁化、规整化」成统一 DataFrame 接口，配套可视化、选股、回测三个能力层。

- 四模块：**data**（数据获取）、**plot**（可视化，matplotlib + pyecharts）、**stock**（选股）、**backtest**（向量化 + 事件驱动回测）。
- 形态：纯 Python 函数库，面向 jupyter notebook / CLI；无 Web、无数据库，数据随调随取、内存往返。
- 盈利模式：README 明确「部分策略选股和策略回测功能仅供知识星球会员使用」，开源版里这些函数是「抱歉，该接口仅限知识星球会员」的占位 stub。
- 依赖要点：`requests/pandas/numpy/matplotlib/bs4/py_mini_racer(py_mini_racer)/pywencai/tqdm`；问财功能需另装 `pywencai` 最新版 + Node.js + `npm install jsdom`。

## 3 分析逻辑

### 3.1 选股模块（`stock/stock_pool.py` + `ths_em_pool.py`）

**RPS 相对强度**（`RPS.cal_rps`）：对某窗口涨幅截面排序，`rps = (1 - n/len) * 100`（排名越靠前 RPS 越大，最高 100）；`all_rps(w)` 先算 `data/data.shift(w)-1` 再逐列套 `cal_rps`。默认窗口 `[5,20,60,120,250]`。

**MM 趋势选股（Mark Minervini Trend Template）**：文档注释列了 7 条标准（>150/200 日线、150>200 日线、200 日线升 1 月、>50 日线、距 52 周低点 >30%、在 52 周高点 25% 内、RS≥70 且与 RPS>90 结合），**但源码 `MM_trend` 是知识星球会员 stub**。

**财务指标打分系统**（`indicator_score`，开源可用、依赖 tushare）：对 10 项指标做 0~10 分打分求和得「总分」。核心打分函数：
- `cal_yoy(y,a)`：同比增长类（营收 a=10、利润 a=20、ROE a=15）——`5 + clamp(round(y-a), -5, 5)`，y≥a 才得分递增。
- `cal_exp(y,a)`：比率类（毛利/费用率 a=0.5、存货周转 a=2、现金流 a=4）。
- `cal_roa(y)`：ROA 从 5% 起步，`round((y-5)/0.5)` 每 0.5% 加 1 分、上限 10。
- `cal_pepb(y,a,b)`：市净率 a=3,b=0.4；PEG a=1,b=0.1——估值越低分越高。
- 派生指标：`gpm=毛利-rolling(3)均价`、`inv=周转率偏离 rolling(3)*100`、`ocf=现金流3季和与EPS3季和的比值*100`、`peg=pe_ttm/净利增速rolling(3)`。
- 汇总列：`['营收得分','利润得分','费用得分','周转得分','现金得分','净资产得分','总资产得分','总分']`。

**同花顺技术选股池**（`ths_pool`/`ths_em_pool`）：把「创新高/新低」分级（历史/一年/半年/月，n=1~4）、`u{n}/d{n}`（向上/向下突破 n 日均线，n∈{10,20,30,60,90,250,500}）、连续上涨/下跌、持续放量/缩量、量价齐升/齐跌、险资举牌、强势股池，统一路由到 `data.10jqka.com.cn/rank/` 系列接口并解析成 DataFrame。

**东财涨停池**（`limit_pool/stock_zt_pool`）：`getTopicZTPool` 返回列含 `连板数/首次封板时间/最后封板时间/封板资金/炸板次数/涨停统计`；`涨停统计` 是 dict，解析成 `days/ct`（N天M板）；时间戳 `133925` 截取成 `13:39`；价格 ÷1000、金额 ÷1000000 归一。

### 3.2 回测模块

**向量化回测**（`vec_backtest.py`）：
- `data_feed`：个股复权价 + 基准指数 `close.pct_change` 拼接；`trade_performance` 输出总收益率/年化（`(1+总)^(250/len)-1`）/最大回撤/夏普（`√len×mean/std`，无风险 3%/年折日）/Alpha/Beta（CAPM 回归）/年/月/周胜率。
- 内置 3 个策略函数：
  - **MR_Strategy（均值回归）**：`score=(rets-rolling(lookback=20).mean())/std`；`score<-1.5` 且次日开盘未涨停（`open<昨收*1.097`）买入、`score>1.5` 且未跌停（`open>昨收*0.903`）卖出；涨跌停按 ±9.7%/±9.7% 近似（未分板块制度）；信号 `shift(1)` 避免当日偷价。
  - **North_Strategy（北向资金布林）**：北向资金 `window=252` 均线 ±1.5 倍标准差上下轨，突破上轨买、跌破下轨卖。
  - **TT_strategy（海龟择时）**：`H_N1=high.rolling(20).max()` 突破买、`L_N2=low.rolling(10).max()` 跌破卖。
- 交易成本 `cost`（佣金+滑点）默认 0.0，可设。

**事件驱动回测**：`turtle.py`（`TurtleSystem` 海龟，sys1 入 20 出 10、sys2 入 55 出 20、`getStratStats` 输出夏普/Sortino/最大回撤及回撤持续时间）+ `bt_backtest.py`（事件驱动框架）；`bt_backtest.py` 主体为空壳（仅 import），实际事件驱动逻辑在 `turtle.py`。

## 4 最终产物结构与格式

- **数据接口产物**：统一 pandas DataFrame，中文列名（`realtime_data` 用 `trade_detail_dict` 把东财 `f12→代码`、`f3→涨幅` 等字段映射成中文）；金额/价格已做单位换算（百万→亿）。
- **回测产物**：`trade_performance` 返回一张 `result` DataFrame（总收益率/年化/最大回撤/夏普/Alpha/Beta/胜率），并可 matplolib 画「策略累计净值 vs 基准 vs 买入持有」；`trade_indicators` 打印每笔交易明细与统计（交易次数/最长持有/平均涨幅/最大盈亏/年均次数/最大连赢连亏）。
- **可视化产物**：pyecharts 输出 HTML（`kline/HA_kline/树状图/ichimoku云图/词云/地图` 等，`notebook=False` 时存本地）或 matplotlib 内联图。
- **问财产物**：`qs.wencai('选股条件')` 直接返回 pywencai 的 DataFrame。

## 5 坑与注意事项

1. **知识星球付费墙**：`RPS.date_rps`、`find_price_vol_stock`（量价突破）、`MM_trend`、`moneyflow_stock` 等核心策略函数是打印「仅限知识星球会员」的 stub/pass，开源版选股能力打折。
2. **README 自曝的 bug**（原文）：业绩快报 `financial_statement('yjkb')`「调用将报错」；`north_money('个股',5)`「列名没有对应起来，该函数调用将报错」——README 直接标注「将在新版本修正」，使用前需知。
3. **指数与股票代码冲突**：平安银行 `000001` 与上证指数 `000001` 同码，README 明确要求指数用简称（`sh/sz/cyb/hs300/sz50` 等），否则 `get_data` 会取到股票。
4. **同花顺接口不稳定**：README 原话「同花顺数据接口不太稳定，如报错过一段时间再试」；`data.10jqka.com.cn` 需 `ths.js` 动态生成 `v=` Cookie + 随机 UA，反爬严格。
5. **问财依赖重**：需 `pywencai` 升级到最新 + 安装 Node.js + `npm install jsdom`，否则 `wencai()` 无法用。
6. **涨跌停近似口径**：`MR_Strategy` 用 `1.097/0.903` 判定涨跌停，是主板 10% 近似，未区分创业板 20%/北交所 30%/ST 5%，策略信号对 20cm 票会失真。
7. **历史波动率/复权差异**：`get_data` 默认 `fqt=1` 前复权，但部分计算（如跨年收益）对复权口径敏感，README 未统一说明各策略应使用哪种复权。
8. **部分数据接口感叹号**：`news_data('js')` 等依赖第三方（金十）平台的反爬 token，升级后可能失效；`data/wencai.py` 里的 URL 列表（`iwencai.com/traceback/...`）是 pywencai 内部实现，qstock 只是透传。
9. **未做持久化/缓存**：所有数据随调随取、无本地缓存，反复调 `realtime_data`/`get_data` 会重复请求东财，高频使用有封 IP 风险（README 未提及限速）。

## 6 可借鉴的设计要点

1. **「数据接口统一成 DataFrame + 中文列名」的产品化思路**：用 `trade_detail_dict`/`market_dict`/`ths_code_name` 三张映射表把东财字段名、市场编码、同花顺板块代码统一翻译成中文，降低使用门槛，是「给不会看接口的人用」的典型做法。
2. **财务打分系统的「区间封顶」设计**：`cal_yoy/cal_pepb` 用 `clamp(round(...), -5, 5)` 把极端值限制在 0~10 分，避免单指标异常值主导总分，是可复用的评分归一化技巧。
3. **同花顺 `v=` Cookie 的逆向实现**：`ths_header()` 用 `py_mini_racer` 跑 `ths.js` 生成反爬 Cookie，巨潮 `mcode` 用 base64 JS 加密——是国内公开数据源反反爬的实战范本。
4. **回测两条腿（向量化 + 事件驱动）**：向量化 `vec_backtest` 快而简单适合策略快速验证，事件驱动 `turtle.py` 的 `TurtleSystem` 适合带仓位/风控的海龟原版，符合教学定位；绩效指标齐全（夏普/Sortino/最大回撤及持续时间/Alpha/Beta）。
5. **信号 `shift(1)` 防未来函数 + 涨跌停不可交易约束**：`MR_Strategy` 里「次日开盘价」成交 + 涨跌停过滤，是回测严谨性的两个最小必要措施，注释里写得很清楚。
6. **README 即文档 + 公众号系列文章衔接**：每个接口配参数说明和使用示例，与公众号 8 篇专题文章一一对应，降低学习成本。
