## 一、项目定位

**Vibe Research（VR）是一个 A 股、美股、港股三市场的"投研工作台"**——本地运行的浏览器应用（Node.js + Python），核心思路是：

- **数据层**：内置 168 个数据端点（35 层），全部直连公开数据源，零鉴权（仅 iwencai 和 SEC 需登记联系方式）；
- **AI 层**：不绑定模型——复用用户本机已登录的 Claude Code / Codex / WorkBuddy 订阅，或任意 Chat Completions 兼容 API（DeepSeek、通义、Kimi、GLM、MiMo 等）；
- **执行层**：AI 研究线程被严格约束——无 Shell、无网络、无自由写盘，只能调用 5 个受控工具（列文件、读文件、确定性计算、写阶段产物、写报告），由产品编排器强制走"公司画像 → 财务 → 盈利预期 → 估值 → 风险 → 报告"六阶段流程并机器校验证据引用；
- **产物层**：研究记录、证据链、计算 DAG 全部落盘本机（`.local/`），带防篡改指纹链。

产品定位边界：只产出研究数据、分析框架、情景概率与裁决点，**不提供买卖建议、目标价、止损位**。

## 二、功能全景（8 个一级栏目）

### 1. 首页
- 大盘与全球指数：上证、沪深300、深成、创业板指、道指、纳指、恒指、恒生科技；
- 我的自选：现价/涨跌幅、A 股"离交易所异常波动标准还有多远"（异动接近度）；
- 我的持仓：按交易流水重放出持仓与盈亏（持仓盈亏、当日盈亏），多币种分开合计不换汇；交易时段约 3 秒自动刷新（腾讯行情快照）；
- AI 对话区：每条回答下列"本轮来源"（取了哪些数据、读了哪些网页、引用哪份研报第几页）；回答中每个数字做出处核对，找不到出处的数字替换为"（略※）"。

### 2. 每日复盘
- 市场状态八格：涨跌家数、成交额 vs 20/60 日均值、涨停/跌停/封板率、最高连板、昨日涨停今表现、站上均线指数个数、两融 5 日变化、沪深300 股息率 vs 10 年国债；
- 短线情绪：涨跌分布 23 档、赚钱/亏钱效应、连板晋级（首板→2板→3板…）、连板股明细（首封时间/流通市值/同花顺题材）；
- 中长线：8 指数 5/20/60/250 日与年内涨跌、60 日成交额柱图、两融走势、股债利差；
- 资金去向：行业资金净流入/流出（东财主源、新浪备源）、成交额 Top20、龙虎榜；
- 涨停股按东财行业四档归类（连续集中/今天集中/零散/单只），与前两交易日对比。

### 3. 产业资讯
- **资讯雷达**：新闻、公告与事件线索；
- **产业信号**：GPU 租金（500.farm + Kalshi）、台系供应链月营收（FinMind）、上游大宗期货、DRAM/NAND 现货、锚点公司招聘（Greenhouse/Ashby）。

### 4. 产业研究
- 20 个板块一页一个（人形机器人、AI 算力、HBM、光互联、PCB、半导体国产替代、固态电池、可控核聚变等）；
- 每板块配分步研究提示词：第 1 步先读用户资料库研报 → 再查公开行业研报 → 之后一步产出一页（总览/技术路线/产业链与价值量/全球格局/确定性地图）；
- 板块内容不预填，全部由用户的 AI 当场查资料产出，每个数字要求写来源和年份。

### 5. 研究工具
| 工具 | 说明 |
|---|---|
| **个股深挖** | 概览页：K 线（5/10/20/60 日线、日月周、复权切换）、财报前瞻与复盘（下一份财报日 + 一致预期 + 历次财报后首日涨跌统计）、事件回看（A 股七类事件：业绩预告/增减持/回购/机构调研/龙虎榜/限售解禁，事件前 5 日~后 20 日的相对沪深300 超额收益统计；港美股看业绩公布前后涨跌）。深度研究页：六阶段研究，保留证据、计算过程、来源冲突、数据缺口；报告"推断"分四档可信度；支持多次研究对比、多 Agent 研究过程对比、生成分享卡（PNG） |
| **多空辩论** | 仅 A 股：多视角围绕同一份资料给支持理由、风险、反驳，找未决分歧 |
| **回测** | 自然语言描述规则 → AI 追问补齐 → 历史数据回测。43 项数值指标 + 月/年收益表 + 最深 5 段回撤；费用/滑点前后对照；4 张图（累计收益对基准/水下回撤/月度热力图/年度柱图）；稳健性检验（夏普置信区间、分段、邻近参数网格）。基准：沪深300 / SPY / 盈富基金。内置 4 种规则：买入持有、均线交叉、RSI 均值回归、RSRS 择时（按光大证券 2017 公报公式自实现，18 日回归斜率标准分 ±0.7）。仅回测 A 股个股 |
| **候选池** | 在自选/持仓/指数成分（沪深300、中证A500、500、1000、2000、上证50、科创50、创业板指）中按 PE(TTM)/PB/市值/成交额/换手率区间逐只核对，每条写明满足/不满足/缺数据，不排名不打分 |

### 6. 我的股票
- **自选与持仓**：交易流水记账（期初持仓/买入/卖出/现金分红/送转拆股，按日期重放）；成本法 FIFO 或移动加权；时间加权 + 资金加权（XIRR）收益率；CSV 批量导入流水（本机解析、预览、先备份再写入）；持仓体检（集中度、年化波动、最大回撤、95% VaR/ES、风险贡献、相关性、行业暴露——A 股申万一级、港美股 GICS）；历史情景回放（A 股 5 段大跌期 + 港美各 4 段，按当前持仓比例重放）；防篡改核对（audit/chain.jsonl 指纹链 + 可外存"链头"）；
- **事件日历**：自选/持仓未来 7/30/90 天的财报、解禁、除权除息 + 台账裁决点/复核日/待办合并成一条时间轴，每条带来源；A股取东财预约披露日、美股取 Nasdaq、港股写明无逐只来源；宏观日历（华尔街见闻）默认关闭；
- **定时提醒**：A股收盘后自动生成收盘摘要（15:40）、自选变化（16:15）、判据到期（16:30），进收件箱，可推系统通知/飞书/企业微信/钉钉群机器人。

### 7. 资料库
- **我的研报**：导入 PDF/DOCX/TXT/MD/CSV，本机解析与检索，只有命中片段发给模型；引用格式 `[资料:<id> p.<页码>]`，漏引/错引被机器校验拒绝；
- **研究记录**：按时间保存研究/回测/辩论报告，附 viewer.html 证据查看器。

### 8. 接入 AI
| 接入方式 | 说明 |
|---|---|
| Claude Code 订阅 | 本机 CLI + claude.ai 订阅登录，自动检测 |
| Codex 订阅 | 本机 Codex CLI（0.160.0+）+ ChatGPT 账号 codex login；API key 登录的不可用 |
| WorkBuddy / CodeBuddy | 桌面版自动识别，或官方 CLI |
| 模型 API | 任意 Chat Completions + function calling：DeepSeek、通义、GLM、Kimi、MiMo、OpenAI 等，模板指向官方地址（标注"未实测"） |

还提供 **MCP 接口**（8 个工具：7 只读 + 1 发起研究），可在 Claude Code / Codex / Cursor 里直接调用 VR 取数、发起研究、读报告。

## 三、技术架构

```
本地浏览器工作台（desktop/ React + Vite）
        │
        ▼
投研层：168 个数据端点（datasources/） · 六阶段研究流程
        · calc 确定性计算库（Python） · validator · 报告归档
        │
        ▼
本地 Agent 运行时（orchestrator/ TS） + 模型供应商
按用户所选来源路由（不串联、不互相回落）：
├─ Claude 订阅 → 本机 Claude Code CLI
├─ Codex 订阅 → 本机 Codex CLI（用户自己的 ChatGPT 登录）
├─ WorkBuddy/CodeBuddy → 本机 CodeBuddy Code CLI
└─ 模型 API → Chat Completions（产品本机跑工具循环）
```

**三级约束（不只靠提示词）：**

| 层 | 组成 | 作用 |
|---|---|---|
| 提示层 | methodology/constitution.md（研究宪法）+ .agents/skills/ + calc/SPEC.md | 金融研究纪律、研究流程、计算函数契约 |
| 执行层 | 受控工具白名单（仅 5 个）+ 收工检查 | 研究线程无 Shell/网络/写目录权限；产物缺失或校验不过退回重修 |
| 编排层 | orchestrator + validator + calc + gate | 强制阶段、证据引用、确定性计算、合规边界 |

**研究运行产物**（`.local/runs/<run-id>/`）：`report.md`（报告）、`evidence.json`（证据，带来源与原文引用）、`calculations.json`（计算 DAG）、`conflicts.json`（跨来源冲突不静默取舍）、`manifest.json`（AI 来源/模型/阶段/状态）、`viewer.html`（证据查看器）。

代码规模参考（v2.1.0 发布前验收）：orchestrator 1225 项测试、desktop 346 项、Python 1448 项（calc 311 + backtest 571 + 数据脚本 566）。

### 4.5 数据可靠性设计

- **交叉核对**：关键数据双源互验（如 fetch_profile 腾讯+baostock vs 东财；fetch_financials 新浪 abstract vs 新浪三表原值）；
- **原始留痕**：取数原始响应落盘并记哈希，证据保留来源、资料期与原文引用；
- **缺口诚实**：缺数据记为缺口不当成 0；取不到的写明原因；部分数据标 partial/stale；
- **冲突不静默**：跨来源冲突写进 conflicts.json；
- **口径标注**：复权方式、币种、单位（手/股/万元/百万港元）、TTM 与单季、公告日 vs 报告期都明确标注；
- **防未来函数**：申万行业用变迁史、财务按公告日过滤、指数成分只用当前快照不回填历史。

## 五、与同类项目的差异化亮点

1. **证据链工程**：不是"AI 聊天出报告"，而是每个数字可回溯到证据编号 + 确定性计算 DAG + 机器校验（漏引/错引拒绝通过），美股实测报告数字 142/142 对上出处；
2. **多 Agent 可对比**：同一只股票用 Claude/Codex/WorkBuddy 各跑一次，并排对比取证数、引用率、校验一次通过率、缺口数、耗时（只比过程不比结论）；
3. **AI 无自由权限**：研究线程没有 Shell/网络/自由写盘，只有 5 个受控工具，收工检查由产品执行——对抗模型幻觉的结构性设计；
4. **自建回测引擎**（Python，571 项测试）：确定性计算、费用/滑点对照、稳健性检验、明确"平仓记录<10 条不下结论"；
5. **数据源工程化**：34+11 个来源的优先级、限流、备胎、失效检测、合规分级做得极细（如北交所码号迁移僵尸报价检测、东财风控限流、财联社本地签名）；
6. **本机私有**：研报原文、研究记录、台账全在本机，防篡改指纹链，隐私模式遮金额。

## 七、总结

**Vibe-Research = "168 端点公开数据 + 受控 AI Agent + 证据链校验" 的本地投研工作台。**

- 功能上覆盖：盘面复盘、产业资讯与研究、个股六阶段深挖（A/港/美）、多空辩论、回测、候选池筛选、持仓记账与体检、研报库 RAG、事件日历与定时提醒；
- 数据上直连 40+ 公开来源（A 股 34 + 港美 11 + 另类数据约 10），零鉴权为主，合规分级明确，备胎与失效检测完善；
- 方法论上最大特色是把"AI 做研究"变成**可审计的工程流程**：受控工具白名单、六阶段强制编排、证据引用机器校验、确定性计算库、跨来源冲突留痕、防篡改指纹链。

对做股票分析工具的开发者而言，其 **datasources 端点注册表设计**、**a-stock-data / global-stock-data 两个数据 Skill 的来源清单与降级策略**、以及 **受控 Agent 执行框架（5 工具白名单 + validator + calc DAG）** 都是最有参考价值的部分。
