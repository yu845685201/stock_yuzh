# 一、LLM / 多智能体股票分析框架（19 个）

## 1. TauricResearch/TradingAgents ⭐

- **项目定位**：复刻真实交易机构内部流程的多智能体 LLM 交易研究框架（有 arXiv 论文 2412.20138），全球该领域标杆项目。
- **数据源来源**：行情走 Yahoo Finance（支持美股/A股 `.SS`/`.SZ`、港股/日股等后缀）；基本面对美股取 SEC EDGAR（无需 key，含 point-in-time 原值）；宏观取 FRED（免费可选 key）；舆情聚合 StockTwits、Reddit、Yahoo News/搜索，可选 TypeSafe Jev 过滤社交帖子；可选 Alpha Vantage。所需 Key：所选 LLM 厂商（OpenAI/Gemini/Anthropic/xAI/DeepSeek/Qwen/GLM/MiniMax/OpenRouter/Mistral/Kimi/Groq/NVIDIA 等）之一即可，FRED、Alpha Vantage、TYPESAFE 为可选。
- **分析逻辑**：基于 LangGraph 的多角色流水线——4 名分析师（基本面/情绪/新闻/技术，技术用 MACD/RSI 等指标）并行 → 多空研究员结构化辩论（可设轮次）→ 交易员定价 → 风险团队三方辩论 → 组合经理最终决策。新增记忆日志（回顾历史决策并计算已实现 alpha、生成反思），checkpoint 断点续传，`run_backtest` 网格回测，portfolio-aware 持仓感知。
- **最终产物结构与内容**：决策报告（买入/卖出/持有 + 理由 + 价格锚点），可存为单页 `complete_report.html`；CLI 交互界面实时展示。
- **技术栈与部署**：Python 3.11+、LangGraph、LangChain；pip 安装或 Docker（含 Ollama 本地模型 profile），支持 OpenAI-compatible 端点/本地 vLLM/LM Studio。

## 2. ZhuLinsen/daily_stock_analysis ⭐

- **项目定位**：面向 A股/港股/美股/日韩台股/ETF 自选股的每日自动 AI 分析推送系统。
- **数据源来源**：行情默认内置免费源 AkShare、Baostock、YFinance，可选 TickFlow、Tushare、Pytdx、Longbridge（token 型，补齐量比/换手/PE）；新闻搜索可选 Anspire、SerpAPI、Tavily、Bocha、Brave、MiniMax、SearXNG；舆情（仅美股）Stock Sentiment API（Reddit/X/Polymarket）。AI 模型支持 Anspire、AIHubMix、Gemini、OpenAI 兼容、DeepSeek、通义千问、Claude、Ollama。
- **分析逻辑**：多代理策略问股（均线/缠论/波浪/热点/事件/成长等 15 种内置策略）；单股多维度决策报告流程——舆情情绪、业绩预期、风险警报、利好催化、买卖点位、评分评级。
- **最终产物结构与内容**：每日「决策仪表盘」（评分/趋势/买卖点位/风险/催化/操作清单）与「大盘复盘」；推送到企业微信/飞书/Telegram/Discord/Slack/邮件；含本地 Web 工作台。
- **技术栈与部署**：Python 3.10+、FastAPI WebUI；GitHub Actions 定时（工作日 18:00）、Docker、本地/桌面客户端。

## 3. HKUDS/Vibe-Trading ⭐

- **项目定位**：一条命令赋予 AI Agent 完整交易能力的开源研究工作台（港大 HKUDS 出品）。
- **数据源来源**：`get_market_data` 一键聚合 28 个数据源并智能 fallback——A股/港股走腾讯、东财、baostock、akshare、tushare、gildata；美股走 yahoo/stooq/sina/eastmoney/yfinance/tiingo/fmp/finnhub/alphavantage；加密走 okx/binance/ccxt；外汇金属走 mt5/tickerall；另有 longbridge、futu(OpenD)、pykrx 韩国、india_broker；可选 QVeris 付费聚合（63+ 服务商）。多数免费无 key，tushare/longbridge/finnhub 等需 token。
- **分析逻辑**：自然语言研究 → 数据加载 → 策略代码生成 → 回测引擎 → 验证（Monte Carlo/Bootstrap/Walk-Forward）→ 交付；多智能体团队（投资/量化/加密/风险）；462 个 alpha 因子库基准（Qlib158 + Kakushadze101 + GTJA191）；Shadow Account（解析同花顺/东财/富途交易流水提取行为画像）；多券商组合聚合。
- **最终产物结构与内容**：HTML/PDF 报告、TradingView Pine、通达信 TDX、MetaTrader5 导出，推送多 IM 渠道。
- **技术栈与部署**：Python（pip `vibe-trading-ai`）、FastAPI + React、Electron 桌面、Docker、MCP 插件；LangChain/LangGraph。

# 附二、分析逻辑架构模式归纳

## 模式 1：多智能体辩论流水线（LLM 时代主流）

**结构**：`N 名分析师并行（技术/基本面/情绪/新闻/政策/资金…）→ 多空研究员辩论 → 交易员定价/风控 → 组合经理终审决策`

- TradingAgents 系（原版、astock 7 分析师、AShare 14 Agent、CN 版）：矛盾对抗 + 结构化输出。
- FinRobot：5 角色 + Bull/Bear/Judge 三方辩论，估值由 32 个确定性算子计算。
- UZI-Skill：不辩论，而是 66 位大佬 × 242 条量化规则并行打分 + 22 种机构方法。
- aiagents-stock：6 分析师团队讨论制。
- tradingview-mcp：Tech/Sentiment/Risk 三 Agent 辩论输出五档评级。
- 价值：通过角色约束收敛 LLM 幻觉，商用落地最成熟的范式。

## 模式 2：确定性计算 + LLM 叙述分离

**核心原则**：数字全部由代码/公式计算（pandas、估值算子、回测引擎），LLM 只负责解读、叙事、组织文字。

- FinRobot（估值算子库）、Vibe-Trading（因子库基准 + 回测引擎）、hunter-community（"事实代码算、文字模型写、写完校验"）、LangAlpha、agentii（G1 确定性脚本）、InvestSkill（框架驱动计算）。
- 意义：这是防止 AI 投资分析"一本正经胡说八道"的关键工程手段，已成行业共识。

## 模式 3：传统规则 / 技术指标策略引擎

**结构**：数据 → 指标计算（MA/MACD/KDJ/BOLL/筹码/缠论结构）→ 条件组合触发信号 → 回测/推送

- 选股类：InStock（200+ 条件）、Sequoia-X（6 策略）、KHunter（12 选股 + 8 择时 + ADX 仓位）、screeni-py、limit-up-review（涨停复盘流水线）、jingjia（竞价 5 因子评分）。
- 缠论类：czsc（Rust 核心 + 220 信号函数）、chan.py、chanlun-pro（逐 Bar 增量）、壹缠（多级别联立）。
- 指标库类：TA-Lib、MyTT、ta、pandas-ta-classic：只算不改，输出 DataFrame/序列。

## 模式 4：机器学习 / 强化学习 / 因子挖掘流水线

**结构**：特征工程 → 模型训练（LightGBM/LSTM/Transformer）→ 交叉验证 → 信号/选股 → 回测

- qlib（微软全流程：因子 → 模型 → 组合优化 → 回测）、QuantMind（LLM 进化因子 + 13 模型工场）、AShare-AI-Stock-Picker（LightGBM 二分类）、RL-Stock（PPO）、FinGPT（金融 LLM 情绪/预测）、az 系列 ML 教程类项目。
- 特色：qlib/QuantMind 的 Point-in-Time 数据库与 PSI 漂移告警，代表了 ML 量化的工程成熟度。

## 模式 5：舆情 / 情绪分析管线

**结构**：多平台采集 → 情感打分（词典/微调模型）→ 情绪指标 → 关联股价/推送

- BettaFish（5 类 Agent 论坛辩论 + 微调模型）、TrendRadar（50+ 平台聚合 + LLM 深度分析）、stocksight（Twitter + VADER）、Stock_Market_Sentiment_Analysis（股吧 BI 指标）。

## 模式 6：数据管道 / 交易通道（无分析或轻分析）

- 数据接口类：akshare/yfinance/adata/efinance/Ashare/easyquotation/TickFlow/a-stock-data 等，只做采集-清洗-标准化输出。
- 交易通道类：easytrader（miniqmt/同花顺自动化）、ths_trade（xiadan.exe）、THSTrader（uiautomator2）、openctp（CTP 生态）。
- 平台底座类：OpenBB（多 provider 统一 SDK）、gs-quant（机构衍生品）。

# 附四、总体趋势与选型建议

## 核心趋势

1. **多智能体辩论范式已成主流**：TradingAgents 系（原版/astock/AShare/CN）、FinRobot、Vibe-Trading、aiagents-stock、tradingview-mcp 均采用"多分析师并行 → 多空辩论 → 风控 → 决策"流水线，是当前 LLM 金融分析落地最成熟的架构。
2. **"确定性计算 + LLM 叙述"分离成为工程共识**：FinRobot、Vibe-Trading、hunter-community、agentii 等明星项目共同采用"数字由代码算、文字由模型写、写完校验"的设计，防止幻觉。
3. **A 股数据源两极分化**：免费零鉴权派（mootdx/腾讯/东财/新浪/财联社直连）vs Token 稳定派（Tushare/TickFlow/Longbridge），前者拼成本、后者拼稳定性，多数项目做"多源 fallback + 防封节流"。
4. **Skill/方法论即能力**：ai-berkshire、hunter-community、UZI-Skill、claude-trading-skills、buffett-letters-skill 等把分析框架封装成可安装的 Skill 包，"方法论"本身成为可分发资产。
5. **合规与安全强化**：实盘接入普遍采用 governed orders/确认卡/纸面隔离/盘前风控门（LangAlpha、hunter-community 账本不可篡改、QuantDinger 的 TypeSafe Jev 盘前门、Vibe-Trading 验证层）。
6. **MCP 协议成为 AI Agent 与金融数据的标准接口**：tradingview-mcp、FinanceMCP、maverick-mcp、OpenBB MCP、a-stock-data、TickFlow 等纷纷以 MCP Server 形态暴露能力。
7. **Rust 加速渗透核心路径**：czsc（缠论核心）、QUANTAXIS QARS、hftbacktest、akquant 等把性能敏感内核重写为 Rust。
