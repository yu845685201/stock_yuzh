## 三、详细设计

### T1 单一出处 bold 转换

1. `renderer.py` 新增模块级最小单元（只做替换不做转义——转义语义两边不同，各自保留）：

```python
#: inline bold 单一出处（V4.4 T1）：六维 html 与 digest note 装配共用，
#: 防"同一语义两处实现"再漂移（本次缺陷即六维侧缺席所致）
_MD_BOLD = re.compile(r'\*\*(.+?)\*\*')

def md_bold(text: str) -> str:
    """`**x**` → `<strong>x</strong>`（不成对的孤立 `**` 原样保留）。"""
    return _MD_BOLD.sub(r'<strong>\1</strong>', text)
```

2. `_render_block` 四类文本接入（顺序 = 先 `html.escape` 再 `md_bold`，与 digest `_inline` 同序，`**` 不受转义影响故安全）：heading / para / bullets / note；table 的 `<th>`/`<td>` 在 `html.escape(_cell(v))` 外同样套 `md_bold`（当前单元格无 bold 用法，接入为对称防御，digest 表格单元格同此行为）。
3. `digest.py` `_inline` 改薄封装：bold 部分调 `renderer.md_bold`（`from .renderer import md_bold`，renderer 不反向依赖 digest，无循环），保留 digest 侧 `_esc` 的 None→'—' 语义；正则与替换逐字符相同 → digest 输出逐字节不变（回归测试即证）。

## 五、风险与不做的事

| 风险 | 缓解 |
|---|---|
| 误伤文本中的字面 `**`（如乘号注释） | 正则须成对匹配，孤立 `**` 原样保留；存量扫描证实仅 3 处成对用法；测试加防御断言 |
| digest 薄封装引入输出漂移 | 正则/替换逐字符相同 + 1242 回归全绿即证；如仍有差，回退 digest 侧独立实现（单一出处让位于逐字节红线） |
| 重生成范围扩大 | 仅三日（有产物的全部六维 HTML），未来日自动走新渲染 |

**不做**：不引入完整 markdown 解析（语法清单证实只需 bold）；不改 md 输出（md 侧无恙）；不动"同输入逐字节一致"契约（转换是纯函数）。
