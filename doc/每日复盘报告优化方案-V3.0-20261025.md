## 2. 逐项设计

### W1 炸板率展示 bug（S1，P1）

**现状与证据**：`digest.py:669` 用 `_fmt(senti.get("burst_rate"), 1, True)` 直接格式化
小数再拼 `%`：0.2222 → `+0.2` → "+0.2%"。同页判据表显示"炸板率0.2222"
（criteria values 字符串），注释行与判据表自相矛盾。0.2222 本身正确（分位 5.6% 正确），
纯展示层 bug。附带问题：炸板率是反向指标，带"+"号语义别扭。

**改法**：
1. `digest.py:669` 注释行：burst_rate ×100 后渲染，无符号——
   `炸板率 当日 22.2%（分位 5.6%）`。None 仍渲染 "—"。
2. `aggregator.py` _sentiment_cycle criteria values 字符串：炸板率显示统一为百分数
   （"高度6 / 炸板率22.2%"），与注释行、口径字典（"越高=封板资金越弱"）一致。
3. 为可测试性，把 §二 注释行抽成纯函数 `_sentiment_pct_note(senti, pcts)`
   （免库单测落点）。

**验收**：重跑 20261023 digest，§二 注释行显示
`炸板率 当日 22.2%（分位 5.6%）`；判据表冰点行 values 显示 `高度6 / 炸板率22.2%`。

**不做**：不改 burst_rate 存储口径（保持小数，底层与分位计算不动）。

### W3 口径字典悬空指针（S1，P2）

**现状**：`digest.py:366` 词条"溢价均值…（开盘/收盘口径见情绪章图注）"——图文版
图注只写了"250 日历史分位"，无开盘/收盘口径；读者被迫跳六维报告且六维也不保证有。

**改法**：词条改自包含，直接写明实际口径（已在 `limit_up_premium.py:5` 核实）：

> 溢价均值 = 昨日涨停股今日平均涨幅（**收盘口径**：今日涨跌幅 = 今收/昨收−1，
> 前复权）——接力情绪核心指标

**验收**：口径字典展开后该词条不指向任何外部图注；与链模块实现一致。

### W8 AH 溢价列样式（S1，P4）

**现状**：`digest.py:701-702` 溢价列用 `_pct_cell`（红涨绿跌）。+160% 溢价被染红，
暗示"上涨/好"，但溢价是 A/H 价差非涨跌方向。

**改法**：溢价列改中性色（去 up/down class，保留数值与符号）；表格图注追加一句
"溢价为价差读数非涨跌，不作红绿标注"。AH 5日差（diff）列保留红绿（A 强于 H 有方向
语义，成立）。

**验收**：20261023 重跑后溢价列无红绿着色，diff 列着色不变。

### W4 图文版自足：封板质量与晋级块（S2，P2）

**现状**：解读区证据表引用的核心数字——晋级率（首板 38%/2 板 20%/3 板 0%）、
首封分桶（午后 57 家占 68%、14:00 后 24 家占 29%）、一次未炸 49%、连板溢价中位
-6.31%、涨停聚集头名（业绩预升 7 家）、题材反馈（炸板修复 +0.75%/翻红 53%）——
在图文版数据区全部无对应呈现，读者无法就地核验。

**改法**（零新计算，全部渲染已聚合数据，同源原则不破）：

1. §二 末尾（分位注释行后）新增 **「封板质量与晋级」** 块：
   - 首封五桶横条图：新增轻量 `svg_count_bars(items)`（单色横条，名称|计数）；
     桶标签用短名（竞价/早盘/盘中/午后/尾盘），完整五桶时段定义由口径字典
     "首封/开板/一次未炸"词条兜底，图注不重复。
   - 两枚读数注：`一次未炸 49% · 14:00 后首封 29%`（senti['seal'] 的
     never_broken_rate / late_seal_rate）。
   - 晋级率小表：档位|昨日家数|今日家数|晋级率（senti['promotion']，≤6 行）。
   - 连板溢价一行注：均值/中位/翻红率（money_effect['consec_premium']）。
2. §三 末尾新增两行注：
   - 涨停聚集 Top3：`概念（家数）`（sector['theme_concentration']）。
   - 题材反馈：炸板修复均值/翻红占比（money_effect['burst_recovery']）。
3. 布局约束：digest 保持"一屏一主题"，新增内容仅一根小条图 + 两张小表 + 数行注，
   不新增大图；块尾挂底表指引（"明细见六维§二/§三"）。

**验收**：20261023 重跑后，上列 6 组数字全部在图文版数据区可见；解读证据表中
引用这些数字的行不再"无处对账"。数据缺失日（如分笔未采集）该块整体不渲染并
note 一行原因，不硬造。

**测试**：新增 digest 渲染单测（agg stub 免库）：五桶图/晋级表/两行注的正常与
缺数据降级两路。

### W5 参考判据与定位判据分款渲染（S2，P3）

**现状**：判据表四行同款渲染，"高潮·第二证据（独立）"命中显示"✓ 是"——虽有
"不参与定位"文字在阈值列内，扫读者先看到 ✓，存在误判为高潮命中的风险。

**改法**：
1. `aggregator.py` criteria 结构每行加 `role` 字段：`'position'`（定位判据）/
   `'reference'`（参考判据）。第二证据行标 reference。缺 role 视为 position
   （向后兼容）。
2. `digest.py:641-647` 渲染：reference 行的命中列显示 `✓（参考）`并加灰字
   （`<span class="note">`）；表下恒定一行注："标注（参考）的判据不参与定位判定"。
3. 判据表为 digest 专属渲染（六维 sentiment 章无 criteria 表，已核实），无六维侧
   同步点。

**验收**：20261023 重跑后判据表第四行命中列为灰字 `✓（参考）`；定位结论行
（"情绪周期定位：回暖/震荡"）不变。

**测试**：criteria 构造单测补 role 断言；digest 渲染单测补 reference 行断言。

   `check_digest_numbers.py` 白名单同步兼容两种格式（`（报告§X）` 旧格式保留

### W6 解读文本可读性规范（S4，P3）

**现状**：SKILL.md:232-236 把五要素合成压进"一句话定位"，实际产出 150+ 字嵌套句；
实现细节（config 键名 `review.chan_pool_linkage`、CSV 列名、"21:35 链重跑 seal
口径收紧"等）外漏进用户面正文。数据接地括注（CSV:X/六维§X）是防幻觉义务，
**不在**清理范围——两者须区分。

**改法**（SKILL.md 修订，.zcode 与 ~/.workbuddy 两份同步）：
1. **①一句话定位**改为"主干 + 分解"两级结构：主干 ≤40 字（状态判定 + 机制词），
   五要素（情绪/量价/资金/梯队/缠论）证据移入紧随其后的分解列表或小表，每要素
   仍挂接地括注。正例：

   > 主干：**低位放量修复市——情绪修复领先于趋势修复，指数普涨、接力被弱档
   > 否决系统性抑制**。
   > 分解——情绪：回暖/震荡（高潮未命中：溢价 3.38%<4.0%，六维§二）；量价：双锚
   > 一致放量涨（六维§一）；资金：中性、置信度中（图文§一注）；梯队：6 板、4/5 板
   > 断层（图文§二）；缠论：15 只一买无行业聚集（图文§六）。

2. 新增 **P2-8 读者面语汇边界**：综合研判/观察池/预案正文禁 config 键名、CSV
   列名、链重跑时间戳、口径换轨过程叙述；此类实现信息只允许出现在"昨日核验与
   数据质量点名"表的说明列；数字接地括注（CSV:X / 六维§X / 图文§X）不受此限。
3. 参考判据措辞规范：解读引用"第二证据"类参考判据时必须随文带"不参与定位"
   （与 W5 表下注呼应）。

**验收**：按新规范改写 20261023 定位句作前后对照（附于实施记录）；新 note 中
config 键名/时间戳零出现（check 脚本可加 WARN 规则：正文匹配 `config | \d{1,2}:\d{2}`
模式且不在质量表行 → WARN）。

### W7 转天预案周末触发缝·A50 观察行（S5，P3，两阶段）

内——触发条件在周末情景下无法自行成立，周末消息面缺口无度量工具。A50 期货近似

**改法（Phase 1，本轮授权内）**：
1. `tomorrow_plan.py` 盘前对照基准表（128-149）增加 **A50 观察行**：最新日K收盘 +

3. 锚定日为周五（或节前，距下一交易日 >1 天）时，预案节追加一句提示：
   "距下一交易日 N 天，恒指/纳指期间无新收盘，P1/P3 盘前触发缝由 A50 观察行
   覆盖（不入触发）。"（交易日间隔用库内 A 股日历计算，勿用 workday 推断。）
