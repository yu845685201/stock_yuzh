### 3.2 `_overseas_indices`（新增）与 `_overseas_snapshot`（改造）

```python
def _overseas_indices(self, as_of: str) -> List[Dict[str, Any]]:
    """外围指数 4 指标（overseas_kline_day；窗口=各市场自身日历，与 _index_positions 同构）"""
    # config 读 overseas_kline_indices → [(code, name), ...]；空则返回 []
    # SQL（DataReader._query，参数化）：
    #   SELECT market_code, trade_date, close FROM overseas_kline_day
    #   WHERE market_code = ANY(%s) AND trade_date <= %s
    #   ORDER BY market_code, trade_date
    # 每代码 closes = 升序列表，尾部窗口：
    #   change_pct = c[-1]/c[-2]-1 ；chg_5d = c[-1]/c[-6]-1 ；chg_20d = c[-1]/c[-21]-1
    #   w = c[-61:]（不足 61 行按可得窗口，<30 行 position=None）
    #   position_pct = (c[-1]-min(w))/(max(w)-min(w))*100
    # 数值全部 _f() 两位小数；行数 <21 时对应列 None
    # 返回：[{'name','date'(该市场锚定行),'close','change_pct','chg_5d','chg_20d','position_pct'}]
```

```python
    # SQL 同现状（overseas_market_daily MAX(trade_date) 全行），渲染前按
    # market_name 白名单过滤：{'富时A50期货','离岸人民币','美元兑人民币','港元兑人民币'}
    # 返回结构同现状 [{'date','name','close','change_pct'}]
```

**降级**：`_overseas_indices` 返回空（表空/无 ≤as_of 行）时，渲染层回退旧版两值表
（用 `_overseas_snapshot` 的全量快照行，不白名单过滤），块标题加注"（快照口径，日K缺失）"。

### 3.3 `_holiday_overseas`（新增）

```python
def _holiday_overseas(self, as_of: str, prev_date: Optional[str]) -> Optional[Dict[str, Any]]:
    """假期外围观察（触发条件：锚定日与前一 A 股交易日自然日差 > 3 天）"""
    # 1) 触发：prev_date 为 None → 不触发；days = (date(as_of)-date(prev_date)).days <= 3 → 不触发
    # 2) 区间 = (prev_date, as_of) 开区间（as_of 当日外围变化属"当日%"列，不重复计入）
    # 3) 对 overseas_kline_indices 的 6 指数逐个：
    #    base  = 该代码 <= prev_date 最近行 close（无 → 该行 accum=None）
    #    rows  = 区间内该代码全部行
    #    accum = rows[-1].close / base - 1（首尾比；qfq 口径下与逐日连乘数学等价，
    #            V1.0 §4.1 Q3 已实测差异 0.0000pct）
    # 4) 返回 None（未触发）或：
    #    {'prev_date', 'rows': [{'name','accum_pct','days'(区间行数),'last_date'}],
    #     'last_date': max(各区区间间最新行日期)}   # 渲染层作"截至"标注
```

### 3.4 `_ah_mapping`（新增）

```python
def _ah_mapping(self, as_of: str) -> Dict[str, Any]:
    """A-H 15 只 5 日累计对比 + 溢价率（H侧 overseas_kline_day qfq + A侧 his_kline_day 前复权）"""
    # 0) 读 config overseas_kline_stocks，取带 a_code 的条目（当前 15 条）；空 → {'rows': []}
    # 1) A 侧：his_kline_day WHERE ts_code=a_code AND trade_date<=as_of 尾 6 行
    #    chg_a_5d = a[-1]/a[-6]-1；a_close = a[-1]
    # 2) H 侧：overseas_kline_day WHERE market_code=h_code AND trade_date<=as_of 尾 6 行
    #    chg_h_5d = h[-1]/h[-6]-1；h_close = h[-1]
    # 3) 对齐判定（Q8，市场交易日口径而非自然日）：
    #    H 侧滞后交易日 = hkHSI 在 (d_h, as_of] 的行数（d_h=该股最近行日期）
    #    A 侧滞后交易日 = base_trade_calendar 在 (d_a, as_of] 的交易日数
    #    任一侧 > 3 → 该行 unaligned=True（行内标"未对齐"，不参与 top3 点名）
    #    A 侧滞后数可用 agg 既有 panel/日历，勿为单股重复查日历（先取全市场日历集合）
    # 4) 溢价率：fx = overseas_market_daily 中 fx_shkdcny 最新行 close（无 → premium=None）
    #    premium = a_close / (h_close * fx) - 1
    # 5) 返回：{'rows': [{'h_name','chg_a_5d','chg_h_5d','diff','premium','unaligned'}],
    #          'fx': float|None, 'fx_date': str|None}
```

**SQL 量级**：15 股 × 2 表 + hkHSI 1 次 + fx 1 次 + 日历 1 次 ≈ 33 次轻量查询，
聚合层现状（指数/两融/龙虎榜等）同量级，无性能问题。

## 4. 渲染层细化设计（`src/review/sections/market_env.py`）

`build` 签名不变。原"外围市场"块（`data.get('overseas')` 两值表）替换为下列四块，
追加在"大小盘风格"之后：

```python
# ① 外围指数（日K）——K 线空时降级回快照全量两值表
idx = data.get('overseas_indices') or []
if idx:
    blocks.append({'type': 'heading', 'level': 3, 'text': f"外围指数（{idx[0]['date']}）"})
    blocks.append({'type': 'table',

                   'rows': [[i['name'], i['close'], i['change_pct'],
                             i['chg_5d'], i['chg_20d'], _pct(i['position_pct'])] for i in idx]})
    blocks.append({'type': 'note',
                   'text': '口径：overseas_kline_day（腾讯 ifzq，qfq 前复权，市场自身交易日历）；'
                           '60日位置 = (收盘−60日最低)/(60日最高−60日最低)，与 A 股指数章同构；'
                           '当日/5日/20日为该市场日历累计'})
# ② 汇率与其他（快照，含 fx_shkdcny）——沿用原两值表版式 + 原 A50 口径 note
# ③ 假期外围观察（holiday_overseas 非 None 时）
#    heading: 假期外围观察（{prev_date} 后休市区间，截至 {last_date}）
#    table:   ['指数', '区间累积%', '区间交易日']；accum=None 的行显示 '—'
#    note:    口径：区间 (前一A股交易日, 锚定日) 各市场自身交易日首尾收盘比（qfq）；
#             "截至"随采集推进自动更新，节后首日为完整区间
# ④ A-H/外围映射（ah_mapping['rows'] 非空时）
#    heading: A-H/外围映射（5 日累计，锚定 {as_of}）
#    table:   ['H股', 'A侧5日%', 'H侧5日%', '差值', 'AH溢价%']；unaligned 行差值/溢价列 '未对齐'
#    para:    差值（A−H）绝对值最大 3 只点名（如：中国石化 +5.41pct、…）
#    note:    口径：两侧各自市场日历 5 日累计（当日收盘错一个交易时段，故用 5 日窗口）；
#             对齐=锚定日与该股最近行相差 ≤3 个市场交易日；溢价率 = A 收盘 /（H 收盘 ×
#             港元兑人民币快照）− 1，为参考口径（A 15:00 / H 16:00 / 汇率采集时点三者错位，
#             且两侧复权基准独立滚动，qfq 口径历史随公司行动变化）
```

渲染细节：数值直接用聚合层已 `_f()` 的两位小数；`_pct` 复用现有实现（`f'{v:.0f}%'`）。

## 9. 风险与注意

1. **`_query` 返回 tuple 行**（`_overseas` 现状用 `r[0]` 索引），新方法注意与
   `DatabaseConnection.fetch_all`（dict 行）区分——聚合层统一走 `self.db._query`；
