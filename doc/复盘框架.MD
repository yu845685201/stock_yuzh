# 复盘框架.MD

| 版本 | 说明 |
|---|---|
| V0.9（试用版） | 2026-09-30，复盘报告层方案 §5.1 前置交付物。**判据表阈值为占位值，待用户校准后定稿 V1.0** |

本文件是「复盘教材 + 开发验收依据」：定义每日复盘的四问框架、六维逐维指标口径与解读方法、情绪周期判据表、数据源映射与已知口径局限。报告层（backend/src/review/）按本文件口径实现，两者不一致时以本文件定稿版为准。

---

## 一、四问框架

每日复盘回答四个问题，依次对应下文六维：

1. **今天市场怎么样？**（维度1 大盘环境 + 维度2 市场情绪）——指数位置、量能、涨跌家数、涨跌停对比给出市场整体温度；
2. **钱在哪些方向？**（维度3 板块主线）——行业等权涨跌榜与概念涨停聚集度定位资金主攻方向；
3. **谁在异动？**（维度4 个股异动）——涨停梯队、炸板、放量大涨、新高新低的明细清单；
4. **明天怎么办？**（维度6 结论预案）——情绪周期定位 + 主线候选 + 披露日程 + 风险提示。维度5 业绩估值提供事件背景（业绩雷/喜、估值极端值）。

## 二、六维逐维定义

> 报告章节括号中的编号即本节编号，计算口径与报告层实现一一对应。

### 2.1 维度1 大盘环境（报告章节一）

| 指标 | 计算口径 | 解读方法 |
|---|---|---|
| 指数涨跌与位置 | trade_index_info 当日 change_rate；位置 = (收盘−60日最低)/(60日最高−60日最低) | 位置百分位 <20% 视为底部区、>80% 视为顶部区；涨跌幅看超买超卖后的修复空间 |
| 两市成交额及增减 | 沪深（北交所单独列示）当日 sum(amount)，今 vs 昨差额与百分比 | 缩量阳线警惕持续性，放量下跌警惕加速；万亿为常见情绪分水岭 |
| 上涨/下跌/平盘家数 | 全市场当日 change_rate 三分计数（剔除停牌无成交行） | 上涨家数占比 >70% 为普涨、<30% 为普跌；与指数背离提示权重掩护 |
| 涨停/跌停家数对比 | cross_section 重算（阈值法+护栏，与链模块同口径） | 涨停家数是情绪广度的核心标尺；涨停>100 家属情绪高潮区、<30 家属冰点区（试用参考） |
| 外围指数（日K） | overseas_kline_day 各市场自身日历（qfq） | 当日/5日/20日累计与 60 日位置百分位（与 A 股指数章同构）；假期小节呈现 A 股休市区间首尾累积 |
| 汇率与其他 | overseas_market_daily 快照最新可得 | A50 期货与汇率（含港元兑人民币，A-H 溢价分母） |

**A-H/外围映射观察**（阶段 2，2026-10-04）：15 只 A-H 两地公司 5 日累计对比 + 溢价率。
口径：两侧各自市场日历 5 日累计（当日收盘错一个交易时段，故用 5 日窗口）；A 侧取
his_kline_day（前复权）、H 侧取 overseas_kline_day（qfq），经 config a_code 映射关联；
对齐 = 锚定日与该股最近行相差 ≤3 个市场交易日（任一侧超出标"未对齐"，不参与比较与
点名）；溢价率 = A 收盘 /（H 收盘 × 港元兑人民币快照）− 1，为参考口径（A 15:00 /
H 16:00 / 汇率采集时点三者错位，两侧复权基准独立滚动），只作观察不作结论；"未对齐"
行不得解读为涨跌差异。

### 2.2 维度2 市场情绪（报告章节二）

全部由报告层基于 60d 窗口独立重算（不依赖当日链运行），判定与 daily_review 链模块同口径。

| 指标 | 计算口径 | 解读方法 |
|---|---|---|
| 连板梯队 | 当日连板股按高度分组计数（2板/3板/…/N板），连板数=连续涨停交易日数（剔除盘中开板后回封的口径即连续判定，不可判定行打断） | 梯队完整（各高度连续有股）为健康；断层（3板空缺但5板存在）为辨识度行情 |
| 空间板高度 | 当日最高连板数 | 高度是情绪周期定位的第一标尺：≤2 冰点区、≥6 高潮区（试用参考） |
| 炸板率 | 炸板家数 ÷（涨停 + 炸板家数）；炸板=盘中触板未封住 | ≥50% 强分歧、≤10% 一致性极强（试用参考） |
| 昨日涨停今日溢价 | 昨日涨停股今日 change_rate 均值/中位数；续涨停单独计数 | 溢价均值 >0 为赚钱效应正反馈，≤0 为亏钱效应（打板/接力亏损） |
| 晋级率 | 今日 N 板家数 ÷ 昨日 (N-1) 板家数（N=2..空间高度） | 各档晋级率 ≥30% 视为梯队健康；1→2 板晋级率是情绪先行指标 |
| 情绪周期定位 | 判据表（§3）四态：冰点/回暖/震荡/高潮/退潮 | 结论预案的核心输入，见维度6 |

### 2.3 维度3 板块主线（报告章节三）

| 指标 | 计算口径 | 解读方法 |
|---|---|---|
| 行业涨跌榜（今/5日） | 行业内个股**等权**涨跌幅均值（行业映射 source 优先 sw_2021，缺失股回退 sina_hy，时点匹配）；5 日累计为 5 个交易日 change_rate 等权均值 | 等权口径反映中小票合力，与市值加权口径可能背离（报告注明）；Top10/Bottom5 |
| 板块涨停聚集度 | 概念 sina_gn × 当日涨停股：概念内涨停家数、占成分比 | 涨停聚集前列且占成分比高的概念是当日资金主攻方向 |
| 主线识别 | 5 日行业榜前列 ∧ 当日涨停聚集前列 → 主线候选 | 两套分类体系不同，按名称宽松交叉，仅供观察；连续 2-3 日交叉命中才可确认主线 |
| 高低切换观察 | 今日榜前 10 与 5 日榜前 10 的位次变化 | 新进入=资金新方向；跌出=旧方向退潮 |

### 2.4 维度4 个股异动（报告章节四）

| 明细表 | 口径 | 解读方法 |
|---|---|---|
| 涨停明细 | 按连板数降序，含代码/名称/涨幅/连板/放量倍数/成交额/ST | 梯队关键股（最高板）决定情绪天花板；首板数量决定次日梯队厚度 |
| 跌停明细 | 同结构 | 跌停集中于某板块提示该方向风险释放 |
| 炸板明细 | 盘中触板未封住 | 炸板股次日溢价是情绪恢复度的先行观察点 |
| 放量大涨 TopN | change_rate≥5% 且 放量倍数≥2（config review.volume_surge_min），按成交额降序 | 机构/主力建仓形态观察；涨停+放量双命中股为次日焦点 |
| 60 日新高/新低 | 收盘严格突破前 60 交易日收盘区间（不含当日） | 新高数扩张=趋势市特征；新低扩张=弱势探底 |

### 2.5 维度5 业绩估值（报告章节五）

| 指标 | 来源与口径 | 解读方法 |
|---|---|---|
| 披露日历 | base_disclosure_calendar：未来 5/10 个交易日预约披露家数；当日 actual 回填家数 | 披露潮（季报月）前预约密集期，重点排查持仓股 |
| 业绩预告 | performance_forecast 当日新增：预增/预减/扭亏分类计数 + 代表条目 | 预告空窗期属正常；首亏/巨亏预告次日核按钮需提前规避 |
| 个股估值 | stock_valuation_daily：全市场 PE-TTM/PB 分位数分布（0<PE<500 剔除异常） | P50 为市场中枢；个股 PE 与自身历史分位比较比绝对值更有意义（后者为后续增强） |
| 指数估值 | index_valuation_daily：pe_static 口径（**注明无 TTM**） | 指数 PE 静态口径仅做长期参考 |

### 2.6 维度6 结论预案（报告章节六）

- **情绪周期定位**：引用 §3 判据表（试用版水印）；
- **明日关注**：主线候选（涨停聚集前列概念）+ 梯队关键股（最高板明日晋级）+ 披露日程；
- **转天交易预案**（2026-10-05 新增，判据初版待校准）：情景应对框架，四块结构——
  - 基准定位：情绪周期定位 → 基准策略倾向（高潮=防分歧兑现 / 回暖=跟随确认 /
    震荡=中性观望 / 冰点=等企稳信号（跌停<涨停且溢价>0）/ 退潮=防守降仓）；
  - 盘前情景 P1/P2/P3：恒指、纳指隔夜（假期为累计）较锚定日收盘 ±`overseas_gap_pct`
    （初版 1.5%）分档 → 各档应对（续弱=低开不抢反弹看承接 / 平稳=按验证点 /
    反弹=高开看首小时量能）；基准值表为报告锚定日口径（同锚定日可复现）；
  - 盘中验证 V1/V2/V3：量能（较今日成交额基准 ±`volume_band_pct`，初版 20%）/
    高度股晋级（封板=延续、断板=断层转防守）/ 溢价（转正扩大=接力修复、
    续降转负=亏钱效应）——每验点给「通过 → / 未通过 →」双分支动作；
  - 方向观察（数据驱动）：涨停聚集前列概念、行业领涨对照、60 日新高 vs 新低
    （高低切换跟踪）、龙虎榜机构净买前列、披露扰动；
  - **转天买入候选**（观察池，判据初版待校准）：四类显式规则筛选 × 情绪开放度
    联动 × 每类买入决策树——
    - R1 梯队接力：连板 ≥2 且非 ST 且开板 ≤2 次（封板质量，分笔缺失放行并标注），
      按连板高度/成交额降序；
    - R2 主线跟随：首板涨停且非 ST 且题材命中涨停聚集前列概念，按成交额降序；
    - R3 趋势新高：60 日新高且放量 ≥2x 且当日涨幅 ≥3% 且非 ST，按成交额降序；
    - R4 机构席位：龙虎榜机构净买前列且非 ST（名称近似排除）且不与前类重复；
    - 情绪开放度：高潮仅开放 R1（防分歧）；冰点/退潮不开放候选（冰点给企稳
      信号清单：跌停<涨停且溢价>0且高度回升）；回暖/震荡全开；
    - 决策树三分支（每类候选固定模板）：确认买入（竞价档位+盘中确认）/ 否决放弃
      （竞价低开、透支高开、破位）/ 风控（止损离场规则）——「是否买入」由转天
      走势验证决定，候选≠推荐；
    - 候选为观察名单非推荐，阈值 config `review.tomorrow_plan.buy_rules`；
  - 用途边界（继承 §3）：条件-动作参考框架，**非次日涨跌预测**；仓位为倾向描述
    （防守/中性/跟随），具体仓位由个人风险偏好决定；阈值 config
    `review.tomorrow_plan`，校准定稿流程同情绪判据 §3；
- **风险提示**：炸板率≥40%、昨日涨停溢价均值≤0 等亏钱效应信号 + 数据口径局限；
- **免责声明**：固定文案（免费数据自动生成、不构成投资建议）。

## 三、情绪周期判据表（2026-10-03 校准定稿）

> 判据阈值已按校准提案定稿（依据 `data/reports/sentiment_calibration_20261003_002902.md`，
> 20210101~20260930 共 1,149 对样本）。高潮由「≥6 板 且 ≥5%」降档为「≥5 板 且 ≥4%」——
> 命中天数 39→109、次日溢价区分度保持（+2.38% vs 对照 +1.91%），缓解兜底态占 66.8% 的
> 过严问题；冰点/退潮维持。**用途定位：情绪状态描述与定位，非次日涨跌预测**
> （校准实测冰点/退潮的次日区分度 <0.3pct）。判据再调整时同步本表与 config。

| 周期状态 | 空间板高度 | 炸板率 | 昨日涨停溢价均值 | 典型市况 |
|---|---|---|---|---|
| 冰点 | ≤ 2 板 | ≥ 50% | — | 涨停家数萎缩、跌停>涨停，恐慌未止 |
| 回暖 | 3~5 板 | 20%~40% | > 0 且递增 | 首板晋级率回升、辨识度股出现 |
| 震荡 | 3~5 板 | 30%~50% | ≈ 0 | 梯队断层、方向不明 |
| 高潮 | ≥ 5 板 | ≤ 20% | ≥ 4% | 梯队完整、普涨、涨停>100 家 |
| 退潮 | 高度递减 | ≥ 40% | ≤ 0 | 高位股大面、亏钱效应扩散 |

实现映射（config review.sentiment_rules，规则命中顺序：高潮 → 冰点 → 退潮 → 回暖/震荡；
config `review.sentiment_calibrated: true` 时报告摘除"试用版"水印）：

```yaml
sentiment_rules:
  ice:    {max_streak_lte: 2, burst_rate_gte: 0.5}      # 任一命中即冰点
  ebb:    {premium_mean_lte: 0}                          # 溢价均值≤0
  climax: {max_streak_gte: 5, premium_mean_gte: 4.0}    # 两者同时命中（2026-10-03 定稿）
```

## 四、数据源映射与已知口径局限（必读）

| 数据 | 来源 | 已知口径局限 |
|---|---|---|
| 个股日K | tdx-api（前复权） | 前复权价不等于历史真实价；涨停判定用 change_rate 阈值法+close≥high 护栏 |
| 北交所日K | 通达信官网盘后包（P0-2 方案 B） | **不复权**：除权事件处历史序列断裂（对拍审计监控）；上市首日无涨跌幅，按 N 前缀识别不判定 |
| is_st | his_kline_day（P0-1 DAO 派生） | 口径为「**该行同步时点名称含 ST**」，非该交易日时点真实状态；戴帽/摘帽切换日前历史行存在误标 |
| 行业分类 | sw_2021 主 + sina_hy 回退 | 等权口径；两套体系覆盖不同，跨源比较仅供观察。**行业分类为一级口径**（申万二级成分免费官方路径实测全部受阻，延后——补全方案 V1.4 决策 7） |
| 概念 | sina_gn | 概念成分随更新变动，未回溯（时点匹配按 in_date/out_date） |
| 题材候选（开发项 E） | 自算归因：sina_gn 概念映射 × 当日热度 | **推断口径，非编辑部人工归因**：候选=概念内涨停≥2 家或成分等权涨跌幅≥2%，按热度取前 3；多概念股存在噪声；宽基属性概念（融资融券/沪深股通等）按 config `review.theme_exclude_concepts` 黑名单剔除 |
| 沪深主板 \*ST 板幅（X-16） | limit_pct 规则函数 | \*ST 内部 **5% 与 10% 板幅并存**（实测同日 \*ST岭南 -10.14% 与 \*ST建艺 +4.84% 并存），规则按 is_st 布尔统一 5%——涨停/跌停判定不受影响（阈值下界+close=high 护栏），炸板误报约 0~2 只/日；封板指标 max-price 设计天然免疫。**不修改规则函数**（10% 档确切适用条件未明，收益<噪声） |
| 封板指标（开发项 F） | tdx 分笔自算 | limit_price=分笔 max/min（真实成交价口径，与行情软件涨停价一致）；时段 09:25~15:00 截断（北交所盘后笔）；首封/开板为分笔可得粒度 |
| 龙虎榜金额（开发项 J/D2） | 沪深交易所官网 | **该上榜原因的前五席位合计，非全市场买卖总额**；多原因上榜股按行展示、禁止跨原因求和（当日榜与三日累计榜混加会失真至 8 倍）；机构净买=席位名含"机构专用"归并近似口径 |
| 分笔资金流（D3） | tdx 分笔自算 | 异动子集近似口径（涨停∪跌停∪炸板∪\|涨跌幅\|≥7%∪成交额Top50，单笔≥50万分桶），非全市场 |
| 两融（D1） | 沪深交易所官网 | 数据日期 T-1（交易所次日盘前发布）；融券余额仅深市有值，仅展示融资余额；单一所停更日不计入趋势对比 |
| 解禁（D4） | 巨潮公告（公告制） | 仅含已披露的近端解禁（一般提前 3-5 个交易日），非完整前瞻；占比列为推导值（解禁股数÷最新可得总股本），未解析出股数的行留空 |
| 业绩估值 | THS 财报 + PE/PB 自算 | 指数估值为 pe_static 无 TTM；个股估值分位非个股历史分位；历史估值回填为点时口径（as-of 已披露财报/股本，前复权价×现股本在除权日附近有偏差，分位统计用途下可接受） |
| 情绪历史分位（开发项 B） | sentiment_metrics_daily | 当日值在截至当日（不含）最近 250 个交易日历史分布中的位置；样本不足 30 天不展示；判据阈值为试用版（校准提案见 data/reports/sentiment_calibration_*.md，定稿由用户完成） |
| 外围指数（日K） | 腾讯 ifzq（overseas_kline_day） | 市场自身交易日历（含 A 股休市日）；个股 qfq 前复权滚动口径；双源对拍（↔ gb_*/rt_hkHSI 快照）偏差 >0.5% 在采集报告告警 |
| 汇率与其他 | 新浪（overseas_market_daily） | 当夜数据以最新可得标注日期；A50 期货 change_pct 为本地昨收自算（快照无昨结字段，首条留空） |
| 链 CSV 交叉校验 | data/analysis/daily_review_{as_of}.csv | 报告重算涨停家数与 CSV 不一致时在报告尾部告警（提示链运行时点与库内数据不一致） |

**缺数据标注规范**：某维度输入表为空或链 CSV 缺失 → 章节渲染为「⏳ 待补：{缺什么}（{原因}）」，禁止留空或编造（数据真实性原则）。

## 五、每日流程与命令

```bash
# 1. 采集（编排器 + 北交所日K，波次并行）
backend/run_cli.py sync-review-all
# 2. 分析链（明细 CSV + 交叉校验基线）
backend/run_cli.py analyze run --chain daily_review
# 3. 报告生成（MD + HTML，落 doc/reports/）
backend/run_cli.py review generate
```

报告重算不依赖第 2 步，第 2 步仅提供明细 CSV 与交叉校验基线（缺省时报告自动降级）。
