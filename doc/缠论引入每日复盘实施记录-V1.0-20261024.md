# 缠论引入每日复盘实施记录-V1.0-20261024

## 一、背景与决策链

缠论实战能力验证（2026-10-24 完成，报告 `data/chan_validation/report.md`）结论：
一买/二买在 2015-01~2026-09 全A费后对随机基线超额 +3.87pp / +2.26pp（BH q≈0，
牛熊双态、11/12 年度、三种参数化稳健）；三买负超额（−2.53pp/60日）、三卖无方向证据。
用户决策引入每日复盘，形式经三轮讨论定稿：

1. **直接进 daily_review 链**（而非独立链+合并）——已逐模块核查全部既有模块
   （2026-10-24）：均为「锚定日 + 固定回看尾巴」语义（`tail()/rolling/iloc[-1]`），
   无全窗口依赖，窗口 132d→520d 不影响既有列取值。已接受的两个行为变化：
   ①存疑列更敏感（更长 precheck 窗口可翻出两年内旧断裂，属数据质量可见性提升）；
   ②EMA 系指标 warmup 130→520 浮点级漂移（语义无差别，meta 标记窗口扩展）。
2. **报告第六章独立小节**「缠论背驰候选（左侧，观察池）」，不混入 R 系列
   （左侧布局 vs 右侧追涨，操作节奏不同）。
3. **仅一买/二买**；三买/三卖/卖点体系不引入。

## 三、已知边界与后续可选

- 缠论池日度核验是短窗代理（T+1 涨跌幅），其验证口径为 20/60 日持有；
  滚动战绩解读时注意口径差。
- 信号频率：全市场年均约 480（一买）+ 250（二买）个，单日 0~16 常见；
  冰点/退潮期密度上升（2018/2024 年约 1000 个/年）。
- 后续可选：组合级模拟、30 分钟级别、退市股补数重验（验证报告 §四）。
- 复现：`run_cli.py analyze run --chain daily_review` → `review generate`；
  引擎单测 `pytest tests/test_chan_structure.py tests/test_chan_divergence_buy.py
  tests/test_chan_report_layer.py`。
