## 一、开发项 N1：解禁 PDF 解析增强（痛点 ★★）

### 1.1 现状与根因（V1.0 轮实测，含清单外发现）

- 现行 `unlock_manager.py` 的 `_SHARES_RE` 仅 4 个精确关键词 + 16 字符窗口、`_RATIO_RE` 仅匹配"占总股本比例"精确串——18 份随机样本（覆盖首发/激励/定增/重组/股改/北交所六类版式）实测**股数 7/18（39%）、占比 1/18（6%）**；
- 三类失效模式：① 关键词变体未覆盖（"解除限售**的**股份数量"、"可解除限售的限制性股票数量"、"归属的股票数量"等）；② 关键词/单位被 PDF 换行从中间截断（"解除限⏎售数量"、"557,071⏎股"）；③ 关键词与数字间填充过长（\*ST发展 股东全名 38 字符）；
- 占比取值正确性：全文首匹配可能误取"限售股占总股本"（瑞立科密 77.4538%）而非解禁占比（23.2526%）；
- **清单外发现 ①（重要）**：北交所"股票解除限售公告"版式日期用语为"**可交易时间为** X 年 X 月 X 日"，不在 `_DATE_KEYWORDS` 也不含"上市流通"子串 → **整行不入库**（库内实测 BSE 0 行，样本 4 份全丢）；
- **清单外发现 ②**："归属结果但股票**暂不**上市流通"类公告属非解禁事件，include 词"上市流通"子串误命中，需加排除词"暂不"；
- **清单外发现 ③**："解除限售条件成就"类公告（亿道/神农样本）正文明确"将另行发布提示性公告"，**无解禁日属正确行为**，维持 parse_failed 不入库（不加标题排除——同类公告中源飞宠物含日期，不能一刀切）。

### 1.2 设计方案（V4.1，已实测，与 unlock_manager.py 实施代码一致）

**① 正则替换**（`unlock_manager.py` 模块级常量；V4.1 较 V4 的差异见行内注释）：

```python
# V4.1（2026-10-04 样本外 45 份实测 56%→98%）：尾部扩 数量|总数|股数|合计
# （科创板首发模板"本次股票上市流通总数为 X 股"），词族补 解锁/上市股数/限售股份，
# 名词组容忍换行并加 限售股
_NOUN = r'(?:限\s*制\s*性\s*股\s*票|限\s*售\s*股\s*份?|股\s*票|股\s*份)?'
_KW = (r'(?:解\s*除\s*限\s*售|解\s*锁|上\s*市\s*流\s*通|可\s*解\s*除\s*限\s*售|归\s*属|'
       r'限\s*售\s*股\s*份|上\s*市\s*股\s*数)'
       r'\s*(?:的)?\s*' + _NOUN + r'\s*(?:的)?\s*(?:数\s*量|总\s*数|股\s*数|合\s*计)?')
_SHARES_RE = re.compile(_KW + r'[^0-9%。；]{0,44}([\d,，]+(?:\.\d+)?)\s*(万股|股)')

# 占比：占…总股本/股本总额…%（间隔容忍换行与"股本数字 股的"夹层）
_RATIO_RE = re.compile(
    r'占[^。；]{0,32}(?:总股本|股本总额)[^。；]{0,44}?([\d.]+)\s*%')

# 日期关键词：正则化（容忍换行）+ 新增 可交易时间/可交易日期/上市日期（BSE 与 *ST发展版式）
_KW_DATE = re.compile(
    r'(?:上\s*市\s*流\s*通\s*日\s*期?|解\s*除\s*限\s*售\s*日\s*期|流\s*通\s*日\s*期|'
    r'上\s*市\s*流\s*通\s*时\s*间|可\s*交\s*易\s*时\s*间|可\s*交\s*易\s*日\s*期|上\s*市\s*日\s*期)')
_DATE_RE = re.compile(r'(\d{4})\s*年\s*(\d{1,2})\s*月\s*(\d{1,2})\s*日')
```

**② `parse_unlock_text` 整体替换**（完整函数）：

```python
@staticmethod
def parse_unlock_text(text: str, not_before: Optional[date] = None) -> Dict[str, Any]:
    """PDF 文本 -> {unlock_date, unlock_shares, unlock_ratio}（V4，2026-10-04 实测 18/18）

    - 日期：关键词后向 80 字符窗，取首个 >= not_before 的候选
      （not_before 继续滤历史批次日期——实测 *ST发展 正文 2015/2018 年日期被正确滤除）；
    - 股数：全部命中中优先前置 24 字符含 本次/合计/共计 的（防误取背景段的拟授予数量）；
    - 占比：取与"股数数字字符串"出现位置最近的命中（防误取"限售股占总股本"），
      股数未解析时退化为全文首命中。
    """
    if not text:
        return {'unlock_date': None, 'unlock_shares': None, 'unlock_ratio': None}

    unlock_date = None
    for m_kw in _KW_DATE.finditer(text):
        m = _DATE_RE.search(text[m_kw.end():m_kw.end() + 80])
        if not m:
            continue
        try:
            parsed = date(int(m.group(1)), int(m.group(2)), int(m.group(3)))
        except ValueError:
            continue
        if not_before is None or parsed >= not_before:
            unlock_date = parsed
            break

    unlock_shares = None
    shares_m = None
    all_m = list(_SHARES_RE.finditer(text))
    if all_m:
        shares_m = next(
            (c for c in all_m
             if re.search(r'本次|合计|共计', text[max(0, c.start() - 24):c.start()])),
            all_m[0])
        try:
            value = float(shares_m.group(1).replace(',', '').replace('，', ''))
            unlock_shares = value * 10000 if shares_m.group(2) == '万股' else value
        except ValueError:
            unlock_shares = None

    unlock_ratio = None
    ratio_m = None
    if shares_m is not None:
        best_d = None
        for r in _RATIO_RE.finditer(text):
            for occ in re.finditer(re.escape(shares_m.group(1)), text):
                d = min(abs(r.start() - occ.start()), abs(r.end() - occ.end()))
                if best_d is None or d < best_d:
                    best_d, ratio_m = d, r
    else:
        ratio_m = _RATIO_RE.search(text)
    if ratio_m:
        try:
            unlock_ratio = float(ratio_m.group(1))
        except ValueError:
            unlock_ratio = None

    return {'unlock_date': unlock_date, 'unlock_shares': unlock_shares,
            'unlock_ratio': unlock_ratio}
```

### 2.2 API 规格（实测锁定）

```
GET https://www.csindex.com.cn/csindex-home/perf/index-perf
    ?indexCode={code}&startDate={yyyyMMdd}&endDate={yyyyMMdd}
Header: Referer: https://www.csindex.com.cn/   （与现有 csindex_source 同站同管道）
```

- 字段：`tradeDate / indexCode / indexNameCn(All) / open / high / low / close / change / changePct / tradingVol / tradingValue / consNumber / peg`；
- 实测样例（932000 20260930）：`{"open":3145.94,"high":3146.86,"low":3104.62,"close":3107.26,"change":-21.69,"changePct":-0.69,"tradingVol":26289122476.0,"tradingValue":3372.38,"consNumber":2000.0}`；
- **单位换算**：`tradingVol` 股；`tradingValue` **亿元**（×1e8 对齐库内元口径）；`preclose = close − change`（首条回补取区间前一交易日 close）；`changePct` 直接可用；
- **深度实测**：000985 2005 全年一次 243 条（→ 全历史，按年 21 请求）；932000 自 20230801 起（4 个年度窗请求）；单次年度范围无限制。
- **V1.2 复验补充（2026-10-04 实施）**：① 超宽窗口单请求 20050101~20261009 实测返回 000985 全历史 5284 行（按年切窗保留为防御性设计）；② 932000 实有 **2020 起**基日回溯 1637 行，`init_start_year` 配 2020；③ **WAF 频控**：连续约 10 请求/小时触发 403 临时封禁（拦截页 attack.jinxibei.com，curl/requests 同样中招，数十分钟级自动解除）→ `--init-perf` 限速 10s/请求（`csindex_perf_interval`）+ manifest 断点续跑（`tmp/index_perf_backfill_manifest.json`），封禁即退避、重跑自动续；日常增量 2 请求/日远低于阈值，无影响；④ **change=null 缺陷（实施中发现并修复）**：基日回溯历史（中证全指 2011-08-02 发布日前、中证2000 2023-08-11 发布日前）API 行的 `change` 字段为 null，初版解析整行丢弃 → 表现为"000985 只有 2011 起、932000 只有 2023 起"；修复后 change=null 时 preclose 取前一 API 行 close（首行留空）。**回补终态：000985 5301 行（2005-01-01 起）、932000 1643 行（2020-01-01 起），932000 20260930 样例日与官网逐字段一致**。

### 2.3 设计方案

**① `csindex_source.py` 新增方法**（完整代码）：

```python
PERF_API = 'https://www.csindex.com.cn/csindex-home/perf/index-perf'

def fetch_perf_history(self, index_code: str, start: str, end: str) -> List[Dict[str, Any]]:
    """指数历史行情（index-perf API；start/end 为 yyyyMMdd，实测 000985 可回溯 2005 全历史）。

    单位换算：tradingValue 亿元 -> 元；preclose = close - change。
    返回行与 index_kline_manager 的 trade_index_info 行同构（ts_code/index_code/
    index_name 由调用方补齐，up_count/down_count 留空——中证 API 无涨跌家数）。
    """
    data = self.get_json(PERF_API, params={
        'indexCode': index_code, 'startDate': start, 'endDate': end})
    rows: List[Dict[str, Any]] = []
    for item in (data or {}).get('data') or []:
        try:
            close = float(item['close'])
            change = float(item['change'])
            open_ = float(item['open'])
            high = float(item['high'])
            low = float(item['low'])
        except (TypeError, ValueError, KeyError):
            continue
        rows.append({
            'trade_date': str(item.get('tradeDate') or ''),
            'open': open_, 'high': high, 'low': low, 'close': close,
            'preclose': round(close - change, 4),
            'volume': float(item.get('tradingVol') or 0),
            'amount': round(float(item.get('tradingValue') or 0) * 1e8, 2),
            'change_rate': float(item.get('changePct') or 0),
        })
    return rows
```

## 三、开发项 N3：申万二级成分——THS 路径（痛点 ★）

### 3.1 探路结论与提取规格（实测锁定）

- 官网三路径已死（清单记录）；**THS `basic.10jqka.com.cn/{code}/company.html` 服务端渲染**含"所属申万行业"字段——与 `ths_source` 既有"无 hexin-v"路径同站，普通 UA + Referer 即可；
- 格式（4 样本 100% 统一）：`所属申万行业：</strong><span>{一级} — {二级}</span>`，实测：浦发银行→`银行 — 股份制银行Ⅱ`、宁德时代→`电力设备 — 电池`、海康威视→`计算机 — 计算机设备`、中芯国际→`电子 — 半导体`。

### 3.2 设计方案

**① `ths_source.py` 新增方法**（完整代码）：

```python
COMPANY_URL = 'http://basic.10jqka.com.cn/{code}/company.html'
_SW_RE = re.compile(r'所属申万行业[：:]\s*</strong>\s*<span>([^<]+)</span>')

def fetch_sw_industry(self, code: str) -> Optional[Tuple[str, str]]:
    """公司概况页 -> (申万一级, 申万二级)。页面服务端渲染、GBK 编码（2026-10-04 实测）。

    无命中返回 None（无申万分类/页面缺失，调用方如实计缺）。
    """
    text = self.get_text(COMPANY_URL.format(code=code))
    m = _SW_RE.search(text)
    if not m:
        return None
    parts = [p.strip() for p in m.group(1).split('—')]
    if len(parts) != 2 or not all(parts):
        return None
    return parts[0], parts[1]
```

**② 新 Manager**（`sync/ths_industry_l2_manager.py`，新文件）：

- 目标集：`base_stock_info` 全部 ts_code **减去** `sector_concept_map` 中 `source='sw_2021_l2_ths'` 在册的 ts_code——增量即天然断点（重跑自动跳过已抓）；
- 模式：`--init` 全量（首次 ~5,300 只）；缺省仅增量（新上市 + 缺失，周频 ~几十只）；逐股串行 `ths_interval`（2s）限速，单股失败不阻塞（失败清单入报告）；
- 入库：`db.upsert_concepts`（`concept_code` 沿用 `industry_manager` 对 `sw_2021` 的既有编码规则，`concept_name`=二级名原文如"股份制银行Ⅱ"，`source='sw_2021_l2_ths'`）+ `db.upsert_concept_maps_explicit`（`in_date=快照日, out_date=NULL`，与 industry_manager 快照写入同模式，**不用** sector_sync_base 的 diff 模式——避免临时抓取失败被误记退出）；
- **口径局限（必须标注）**：THS 为当前快照、无 in_date/out_date 历史——二级成分仅"当前时点"准确，历史行业切换不可回溯（一级已有官方时点日期）；复盘框架.MD §4 增补此条；
- 北交所股票无申万分类属正常，如实计缺。**V1.2 复验修正：BSE 股在 THS 有申万分类（海能技术→`机械设备 — 通用设备`、三瑞智能→`国防军工 — 航空装备Ⅱ`），有则采、无则计缺，验收口径相应放宽**。
- **V1.2 实施记录（两处方案修订，均为实跑发现）**：
  ① **concept_code 改用「{一级}—{二级}」组合码**（如"银行—股份制银行Ⅱ"），不再裸用二级名——一级概念以 code=名称 入库（industry_manager sw_2021 规则），裸二级名撞 code 触发 ON CONFLICT 会把一级行的 source 覆盖（实跑事故：钢铁/电力/建筑装饰 3 行被翻，已删行重跑 sync-industry 还原，组合码后结构性免疫）；同表 map 行无污染。
  ② **in_date 用 yyyyMMdd**（sector_concept_map.in_date 为 varchar(8)，ISO 格式触发 StringDataRightTruncation 整批中断）。
  另实测两条 THS 口径细节：**个别页面存在一级名占两段的异常版式**（如「钢铁 — 钢铁」）→ l1==l2 校验后计缺；**老股票（退市股等）页面为申万2014 旧版式**（如黑色金属—钢铁、交运设备—汽车零部件）与 2021 版式并存——组合码天然容纳，报告二级榜按当日面板取数，老版式不进当日排名。

**③ CLI 与编排**：`sync-ths-industry-l2 [--init]` 新命令；`review_sync_orchestrator.py` 的 `WEEKLY_SOURCES` 追加 `'ths_l2'`（周日随 concept/unlock 并跑，增量模式）。
