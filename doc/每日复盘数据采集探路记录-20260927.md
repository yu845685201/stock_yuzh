## 一、可用接口（已按实测实现）

### 1. 深交所（www.szse.cn/api/report/ShowReport/data，GET，Referer 必须 szse.cn）

| 用途 | 参数 | 备注 |
|---|---|---|
| 两融明细 | `CATALOGID=1837_xxpl&TABKEY=tab2&txtDate=YYYY-MM-DD&PAGENO=N` | pagesize 固定 20，全市场 ~106 页；融资买入额/余额（亿元）、融券卖出量/余量（万股）、融券余额（万元）；无融资偿还额列 |
| 龙虎榜列表 | `CATALOGID=1842_xxpl_after&txtStart=…&txtEnd=…&PAGENO=N` | dqrq/zqdm/zqjc/cjje（亿元）/plyy 披露原因；bz 内含明细入口 ZBDM |
| 龙虎榜席位 | `CATALOGID=1842_detal&TABKEY=tab2&DQRQ=…&ZQDM=…&ZBDM=…` | 买1~卖5 × 营业部名称 × 买卖金额（元） |
| 预约披露 | **未定位到目录**（官网改版） | 配置化入口 `review_sync.exchange.szse_plan_catalog`；实际披露日由巨潮公告 pubDate 回填（方案 4.3 COALESCE 规则），本项标"待补" |

注：历史文档中的 80003267（两融）等目录已失效（返回 `noalert@显示报表数据失败`），本文档目录为 2026-09-27 实抓页面 XHR 所得。

### 2. 上交所（query.sse.com.cn，Referer 必须 www.sse.com.cn，日期参数 yyyyMMdd 无横杠）

| 用途 | 参数 | 备注 |
|---|---|---|
| 两融明细 | `commonSoaQuery.do?sqlId=RZRQ_MX_INFO&preStockCode=&beginDate=&endDate=` | 全市场单日 ~2000 条；rzye/rzmre/rzche（元）、rqyl（余量）；无融券余额金额列 |
| 龙虎榜（含席位） | `marketdata/tradedata/queryTradeOpenInfo.do?tradeDate=&secCode=&refType=` | 行按 个股×原因×席位 展开（bsType B/S、branchRank、branchName、branchTxAmt）；refType 为披露原因代码 |
| 预约披露 | `commonSoaQuery.do?sqlId=SSE_SZSGG_DQBGYYQK_CAST_NEW&bulletintype=L011~L014&publishYear=` | L011 年报/L012 半年报/L013 一季报/L014 三季报；publishDate0 预约日、actualDate 实际披露日 |

注意：上交所两接口返回 **JSONP**（`jsonpCallback({...})`），需剥壳（已实现于 sse_szse_source._parse_jsonp）。

### 3. 中证指数公司（oss-ch.csindex.com.cn）

- URL：`https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/file/autofile/indicator/{code}indicator.xls`
- 注意：csi-web-dev.oss…aliyuncs.com 旧地址已收紧 403；oss-ch 域名 200
- 文件为 OLE2 .xls（需 xlrd），近 20 个交易日滚动窗口
- 列：日期Date / 指数代码（短码如 300）/ 指数简称 / 市盈率1（总股本）P/E1 / 市盈率2（计算用股本）P/E2 / 股息率1 D/P1 / 股息率2 D/P2
- **官方文件无 PE(TTM) 口径** → pe_ttm 留空（数据真实性原则）；pe_static 取 P/E2、dividend_yield 取 D/P2（首周按方案 §5.4 抽样人工比对确认口径）
- 404 页为 JPEG 图片体，按幻数 `d0cf11e0` 识别真 .xls
- 中证仅发布其管理指数：创业板指（399006）等深交所指数无文件，已从默认清单移除

### 4. 新浪（hq.sinajs.cn）

- `GET /list={codes逗号拼接}`，必须带 `Referer: https://finance.sina.com.cn/`（否则 403）；响应 GBK
- `int_*`（道指/纳指/标普）：`名称,当前点位,涨跌额,涨跌幅`
- `rt_hkHSI`（恒生）：`HSI,恒生指数,点位,…,涨跌幅(字段8)`
- `fx_*`（汇率）：另类布局，[1]=最新价，日期由尾部 yyyy-MM-dd 扫描定位；涨跌幅无可靠定位 → 留空
- `int_hsi`、`int_dini`（美元指数）实测空返回，未采用；美元指数待找到有效代码后配置补充

### 5. 同花顺个股财务页（basic.10jqka.com.cn）——4.3 首选来源探路通过

- `GET http://basic.10jqka.com.cn/api/stock/finance/{code}_main.json`
- 正常 UA + Referer `http://basic.10jqka.com.cn/` 即可，**无 hexin-v 强制**
- 顶层 `{"flashData": "<JSON字符串>"}`；flash 内 title[i]/report[i]/report_yoy[i] 行列对齐，report[0] 为报告期列表（实测 122 期全历史，yyyy-MM-dd 最新在前）
- 指标：营业总收入、净利润（累计口径）、基本每股收益、每股净资产、净资产收益率、每股经营现金流等 22 项；同比数值在 report_yoy 同下标行
- 实测样例（000001 平安银行 2026-06-30）：净利润 256.96 亿、同比 3.32%、EPS 1.24

### 6. 巨潮全市场窗口检索（hisAnnouncement/query，4.6/4.13）

- `stock=''` + `column='szse'` 即返回全市场（沪深北，column 对检索不敏感）
- 实测 2026-09-25~2026-09-27 三日窗口 totalAnnouncement=806
- 分页口径与既有实现一致（hasMore 驱动 + totalAnnouncement 上限保护）
