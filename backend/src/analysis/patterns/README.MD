## 自建 2 式的判定（无对拍基线，显式声明）

- **红三兵**：连续三根阳线（每根 c>o 且实体占比 ≥0.6）+ 收盘递进；
- **三只乌鸦**：镜像（连续三根阴线，实体占比 ≥0.6，收盘递降）。

## 已知口径边界（诚实声明）

1. **克隆 3 个缺陷形态未纳入对拍清单**：`bullish_hanging_man` 缺文件
   （调用必炸 ImportError）、`evening_star`/`evening_star_doji` 未在克隆 API
   暴露（本库直接 import 类文件，仍对拍）；README 清单与代码三方不一致是
   克隆自身问题（登记在案，勿怪本库）。
2. **强度分级未实现**：TA-Lib 的 ±100/+200 强度口径不在本基线中，模块只出
   形态名不造强度（原则 P3）。
3. **一字板全不命中**：high==low 时 0/0=NaN → 比较 False；hammer 系
   `(h-l)>3*(o-c)` 亦不成立。A 股涨跌停场景的结构性事实，解读时勿当缺陷。
4. **分母口径刻意保留差异**：doji 系用裸 `(high-low)` 分母（复刻克隆），
   hammer 系用 `.001+` 分母——统一即偏离基线，禁「顺手优化」。

## 实现结构

- `spec.py`：方向常量 + PatternSpec（独立模块防循环 import）；
- `geometry.py`：几何工具，统一 `.001+` 防除零门；
- `base.py`：`detect_all` 向量化检测（numpy 数组运算，禁逐行循环——模块规范
  第 3 条）+ 注册表 + `load_all` 导入期自检；
- `single/double/triple.py`：判定式（与克隆逐字对应）。
